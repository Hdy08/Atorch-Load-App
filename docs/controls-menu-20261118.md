# 菜单、数值输入与图表文案（2026-11-18）

应用中的单选下拉统一使用官方 Fluent `Menu`，以按钮显示当前选择，弹出菜单显示选中状态。支持键盘打开、方向键导航、Enter 选择、Escape 关闭和返回触发按钮。USB 采样率、曲线时间与范围、分页、外观、自动连接、自动记录条件、固件 USB 设备选择共用 `MenuSelect`。选择值及原有持久化键保持兼容。

所有可编辑数值共用 `NumericInput`：官方 Fluent `SpinButton` 的输入框、单位（如有）和右侧上下按钮。负载控制、悬浮目标值、设备参数及校准、界面缩放、曲线上下界与线宽、阴影不透明度、记录阈值及保持时间、跳转页码使用同一组件。文本颜色值、文件选择继续使用各自的输入类型。

手动输入即时保存到草稿；清空、负号及小数编辑不强制取整。原有提交校验、设备写入确认、范围与手动精度保留。负载相关步进仍按各参数的整数倍网格处理，允许手动输入的细精度值；粗调不会越过保护值。记录延迟／保持时间保留一位小数。数值控件的箭头不会提交表单或直接写入设备，悬浮目标值仍由 Enter 提交。

曲线时间坐标的显示名称由“真实时间”改为“绝对时间”；内部 `clock` 值保持兼容。“重置缩放”改为“复原”，“退出全屏”改为“退出”，“导出 CSV／导入 CSV”改为“导出／导入”。文件格式及导出范围不变。

全屏曲线的第一行仍包含参数复选项和退出按钮。第一行与绘图区之间的间距等于第一行距窗口顶部的间距；按工具栏实际高度与安全区域顶边距计算，兼容界面缩放及旋转显示。

曲线下方的操作区按实际可用宽度判断是否容纳完整按钮：空间不足时整组改为图标按钮，扩大后恢复文字。实时与历史共用同一行为；暂停／继续、清空、导出、截图、复原和全屏始终保留可访问名称，悬停显示对应提示。

本版同时包含 [手机图表触屏手势](chart-touch-20261118.md)：双指在纵轴区域缩放对应单位；长按图内框选时间范围；长按纵轴按格平移。普通单指滚动页面和横向拖动时间轴保持可用。

安装包、构建与测试日志归档在 `artifacts/controls-menu-20261118`。验证详情以该目录的 `release-report.json` 为准；浏览器自动化使用模拟设备数据，没有操作 BW150。
