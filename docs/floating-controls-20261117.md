# 实时页悬浮控制与数值格式（2026-11-17）

本次将实时页的大型负载控制卡片改为右上角悬浮控件，统一图表浮窗、统计表与明细的原始精度和小数点对齐，同时修复客户端标题栏顶部边框并精简固件显示。

## 负载控制

- 悬浮控件仅在实时页显示，水平排列为模式标识、目标文本与输入框、设置图标、启停图标；最右侧始终为启停。
- CC / CV / CR / CP 分别显示恒电流、恒电压、恒电阻、恒功率；目标值保持相应输入精度，单位位于框内。只有回车才校验并提交，失焦不写入，重复回车不会重复发送。
- 校验沿用现有目标、截止与保护范围，命令携带编辑时的模式上下文。提交期间锁定控制，成功后读取设备参数。
- 设置弹窗标题为“负载控制”，包括“快速设定”“模式切换”。快速设定保留目标、截止电压、过流、过功率、运行时限五项，增加 MOS 与 NTC 温度上限；保持连续滑块、内嵌单位输入框、应用按钮和原有步进。
- 专用模式隐藏目标文本与快速设定页签，不计算普通目标输入范围；保留模式切换及原有专用阶段区域。
- 启动保留确认，停止直接提交；运行状态未知、阶段选择待处理、升级占用等限制仍生效。BLE 保留面板遥控，不将未知状态当作可精确启停。
- 实时页通知下移避让悬浮控件；其它页面隐藏悬浮控件、取消页首占位，通知回到正常顶部位置。

实现入口：`FloatingLoadControl.tsx`、`App.tsx`、`Notifications.tsx`、`styles.css`。

## 数字显示与温度顺序

- CSV 后台解析时收集每个通道的最大小数精度，保留尾随零和科学计数法。精度元数据按整份数据缓存，作为固定大小对象随 Worker 传输，不为每一行复制元数据。
- 图表浮窗和明细按原始通道精度补零。USB 监测字段按协议的千分之一单位保留三位；BLE 电压、电流、容量、MOS 温度分别采用已解析字段精度。计算值显示三位小数。
- 统计的最小值、最大值保留对应极值来源的原始精度；计算得到的极值与平均值使用三位。累计电量、容量仍不计算平均值。原始累计值与积分值混合时，按各极值自己的来源决定格式。
- 数值采用等宽字体，将整数和小数部分分列排版。不同精度共存时预留相同的小数区域，使个位、小数点分别对齐；数值表头右对齐。
- 浮窗按各曲线在同一采样时刻的实际屏幕 Y 坐标从上到下排列，考虑各自单位轴及缩放；普通曲线与大文件曲线使用相同格式。
- 格式处理只影响显示，原始数值、积分及 CSV 完整导出保持原值。高精度补零直接扩展十进制表示，避免额外引入浮点尾数。
- “探头温度”统一改为“NTC 温度”；卡片、参数选择器、曲线设置和明细列按 CPU、MOS、NTC 排列。保护设置中的温度上限按 MOS、NTC 排列。

实现入口：`measurementFormat.ts`、`csv.ts`、`csv.worker.ts`、`csvTransfer.ts`、`csvImport.ts`、`records.ts`、`analysis.ts`、`chartData.ts`、`DataReview.tsx`、`TrendChart.tsx`。
