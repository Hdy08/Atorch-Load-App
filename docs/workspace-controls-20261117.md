# 页面布局、可拖动控制器与 BLE 计算（2026-11-17）

本轮统一页面与悬浮层的布局，将蓝牙面板按键集成到实时页控制器，并补齐 BLE 缺少的电阻、电量。

## 布局与通知

- 客户端标题栏的 1 像素顶部线改为低对比度边框，去掉导航栏右侧分隔线。
- 主区域统一在标题栏下方独立滚动。页面右侧留白包含滚动条自身宽度，不再额外叠加一份滚动条宽度；宽屏最大内容宽度也使用相同补偿。
- 页面边距统一为桌面 24 像素、手机 16 像素；同组读数小卡片间距保留 12 像素，普通卡片网格与页面卡片间距统一为 16 像素。
- 实时监控、数据记录、设备设置、应用设置共用标题高度和位置。应用设置的页签与内容直接使用主页面间距，首排卡片与数据记录、设备设置对齐。
- 控制器默认右边缘与卡片区域右边缘对齐，通知使用同一布局测量结果；窗口缩放及滚动条出现、消失时同步更新。
- 通知按内容展开，最大宽度限制为当前页面卡片所在内容区宽度。实时页默认通知位于控制器下方。
- Toaster 的动态边界通过文档 CSS 变量传入，避免 Fluent 定位逻辑修改被 React 冻结的 style 对象。
- 曲线参数勾选栏仅显示名称和颜色点，实时、当前记录、历史记录共用。坐标轴、图表浮窗与数据表中的单位继续显示。
- 手机禁用页面双指缩放：viewport 固定缩放比例，触屏滚动容器允许单指平移，Android WebView 原生关闭缩放及缩放控件；图表自身的缩放与拖动逻辑保持可用。

## 悬浮控制器

- 仅在实时页显示；USB 保留模式、可回车提交的目标值、设置图标、启停图标。
- 最左侧增加拖动手柄，使用 Pointer Capture 支持鼠标及触摸。控制器可在导航栏右侧整个页面范围内移动，避免进入标题栏、侧栏、底部移动导航或越出窗口。
- 手柄支持方向键移动，默认每次 10 像素，Shift 配合方向键每次 40 像素。
- 拖动只重绘控制器；位置保存在本次运行的内存中。切换页面再返回保留位置，重新打开应用恢复默认位置；窗口改变大小时限制在新边界内。
- BLE 从左到右为手柄、蓝牙图标、`SET`、`-`、`+`、`OK`、设置图标。四键分别发送一次 `keySet`、`keyMinus`、`keyPlus`、`keyOk`，点击 OK 直接发送，不再弹出确认键窗口。
- BLE 设置弹窗标题为“负载控制”，只显示一个“蓝牙控制”页签，包含清零设备电量、容量、计时三个按钮。三项清零仍需确认。

## BLE 计算

- 采集层对每个有效蓝牙监测帧计算电阻：电压除以电流的绝对值；电流为零时为 0，不产生无穷大。
- 电量从本次 BLE 连接的 0 Wh 开始，按实际收到的时间戳对功率绝对值作梯形积分。内部积分保留精度，实时卡片、图表浮窗、统计和原生 CSV 按三位小数显示或输出。
- 断连或系统时间异常造成的负间隔、超过 5 秒的间隔不补积分；新连接使用新的累计状态。暂停采样不停止实时监测及累计计算，与 USB 累计值继续变化的行为一致。
- 成功发送蓝牙电量清零命令后，本次连接的计算电量也归零。容量、设备计时清零不重置本机计算电量。
- 计算结果进入同一份快照、曲线历史与原生记录。USB 不经过该计算器，重新连接 USB 后采用设备返回的实际电阻、电量。

## 页面过渡

应用设置 → 外观新增“页面过渡动画”，提供平移、淡入、缩放、无，默认平移，选择保存在本机。采用 Web Animations API 与 Fluent 的时长、缓动 token，只对进入的主页面做合成动画；标题栏、导航、控制器不参加动画。系统开启“减少动态效果”时禁用动画。

实现入口：`App.tsx`、`FloatingLoadControl.tsx`、`BleControls.tsx`、`Notifications.tsx`、`MeasurementSelector.tsx`、`usePageLayout.ts`、`usePageTransition.ts`、`styles.css`、`crates/device/src/ble_measurements.rs`。
