# 手机曲线触屏手势

实时、当前记录、历史记录及全屏共用以下触屏操作。

| 区域             | 手势                   | 结果                       |
| ---------------- | ---------------------- | -------------------------- |
| 绘图区           | 双指捏合               | 缩放水平时间范围           |
| 某个纵轴的刻度区 | 双指捏合               | 只缩放该单位轴             |
| 绘图区           | 单指长按后左右拖动     | 框选水平时间范围，松手提交 |
| 某个纵轴的刻度区 | 单指长按后上下拖动     | 按当前每格跨度整格平移该轴 |
| 绘图区           | 普通单指水平滑动       | 平移当前时间范围           |
| 图表区域         | 长按完成前单指上下滑动 | 滚动页面                   |
| 下方范围条       | 拖动选区及两端手柄     | 保留原有范围调整           |

长按约 450 毫秒触发。触发前手指移动超过约 8 个屏幕 CSS 像素时取消长按等待，不将普通滑动改为框选或纵向平移。短暂点击不触发框选或纵向平移。

纵轴捏合在手势开始时锁定单位和锚点，以开始时的范围、双指距离计算变化，使用平方根减弱灵敏度；触摸事件数量不会累积放大缩放量。缩放使用既有精确刻度、1／2／5 步长、幅值上限及原始采样可见性约束。横轴及其它单位轴不因纵轴捏合而改变。长按纵轴平移保持当前格数及每格跨度，不重新套用自动刻度公式。

水平框选支持向左、向右拖动，限制在绘图区内，最小时间跨度为 1 秒。允许选择没有采样点的暂停空档。拖动框选期间显示原有整高选区，实时采集与记录继续，松手后补上显示更新。

第二根手指加入会取消尚未提交的长按框选或单指拖动，并转入双指识别；触摸取消、窗口失焦或卸载曲线会清理长按计时、指针捕获及选区，不提交框选。双指变为单指后不突然接续另一个拖动，抬起后可开始新的手势。全部已选参数无有效值时禁用捏合、长按框选和纵向平移。

坐标统一由屏幕位置换算到图表逻辑位置，支持手机默认 75% 缩放、竖屏、正常横屏及旋转全屏。浏览器页面缩放保持禁用。

构建和回归材料位于 `artifacts/chart-touch-20261118/`。触屏界面验证使用 Chromium 的触摸输入及模拟原生 IPC，不替代 Android 实机验收；本轮不操作 BW150。
