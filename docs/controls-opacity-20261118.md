# 控件宽度与曲线不透明度（2026-11-18）

单选菜单按钮按列表内最长选项的实际文字宽度确定尺寸，切换到较短选项时保持相同宽度。外观、连接、自动记录、曲线时间与范围、USB 采样率、分页和升级设备共用该规则。按钮只在容器空间不足时收窄并截断文本，完整选项仍可从菜单查看。隐藏的宽度测量不进入可访问名称，也不依赖固定像素或字符数量。

每个曲线设置卡片底部使用两列：左侧为曲线不透明度，默认 100%；右侧为阴影不透明度，默认 0%。均支持 0–100%，输入框内显示百分号与上下微调按钮。曲线与阴影分别生效；曲线为 0% 时数据仍保留。所有参数共用实时与历史设置，应用更改后记忆，恢复默认后为 100%／0%。旧版本未保存曲线不透明度的配置按 100% 处理。

持久化键仍为 `atorch-chart-bounds`。每个通道新增可选 `lineOpacity`（0–1），默认值可省略；`areaOpacity` 保持独立。载入时丢弃非法透明度值，保留同一通道其它有效设置。图表与截图共用 ECharts 的线条不透明度。

强调色文本框完整容纳 `#RRGGBB` 七个等宽字符，并预留编辑空间和左右留白，内置取色器按钮保持独立间距。所有菜单按钮的当前选项文字左对齐。颜色来源、预设色、系统取色和手动输入行为不变。

本版同时包含 [菜单与数值输入统一](controls-menu-20261118.md) 和 [手机图表触屏手势](chart-touch-20261118.md)。安装包、源文件哈希和测试结果归档在 `artifacts/controls-opacity-20261118`，实际验证范围及限制以其中的 `release-report.json` 为准。
