# 曲线交互、悬停圆点与单行参数栏（2026-11-17）

本轮修改实时、当前记录和历史记录共用的曲线组件，未更改设备通信、启停命令或自动记录规则。

## 鼠标与悬停

绘图区的鼠标 / 笔拖动通过 Pointer Events 直接处理，按手势开始时的范围和物理指针位移计算时间平移，使用指针捕获保持移出画布后的手势。拖动期间继续采集，绘制更新仍在松开后补上；下方范围条继续使用原有交互。保留桌面 Ctrl + 滚轮缩放，普通滚轮滚动页面，纵轴只缩放当前单位轴。

圆点按浮窗对应的同一条原始采样绘制，每条已选曲线至多一个，不依赖抽稀显示中是否保留该点。缺失数据及超出当前坐标范围的数值不绘制圆点，离开绘图区或清空数据时移除。圆点使用各通道颜色，鼠标静止时可随新数据保持更新；它们不增加图表的采样点数，也不进入 CSV 或统计。

普通画布保留渲染器的原生鼠标偏移，以避免在高密度数据中因亚像素取整改变所选原始行；仅旋转全屏回退使用物理坐标映射。程序触发的浮窗事件使用已有图表坐标，不重新当作物理鼠标事件处理。窗口尺寸变化的画布更新按帧合并。

## 参数与全屏

参数栏使用官方 Overflow、Checkbox 和 Popover 组件，始终保持一行。可用宽度不足时依次隐藏后面的选项并显示“更多”，点击按钮显示 / 隐藏其余复选框。勾选状态和选择顺序沿用现有共享偏好，不因参数暂时隐藏而清除。

全屏顶部左侧为相同的单行参数栏，右侧为退出全屏。无需退出即可更换曲线，实时、当前记录及历史记录同步。全屏继续复用同一个 ECharts 实例并保留当前时间范围，退出后恢复原卡片高度与焦点。手机无法锁定系统横屏时，参数弹层按旋转后的逻辑容器定位，避免移到屏幕外。

## 验证与交付

回归包含 75% / 100% / 150% 缩放、普通与两万点数据的鼠标拖动 / Ctrl 滚轮 / 圆点、连续采样过程中的拖动、范围条、浮窗与原始精度、导出、手机双指缩放、旋转全屏及“更多”参数同步。25 万点 CSV 检查完整导出、按像素抽稀、原始浮窗值和六个圆点的坐标，同时保留原有性能阈值。

原始日志、界面截图、按用例取最新结果的汇总及构建检查位于 `artifacts/chart-interaction-20261117/`。浏览器测试使用模拟 IPC；本轮未连接 BW150 进行设备操作，也未重新进行 Android 实机旋转验收。
