# USB 固件更新

Windows 和 Android 的**设备设置 → 固件更新**提供文件检查、目标选择、刷写进度和传输日志。

1. 停止负载和录制，移除测试输入，关闭正在占用 USB 设备的其他程序。
2. 选择与设备匹配的升级文件，检查大小与摘要。在**选择 USB 设备**卡片中选择目标，必要时点击**刷新**。
3. 点击**刷写**并核对确认窗口中的设备、文件与摘要。更新期间保持设备供电和 USB 连接。Android 重新枚举设备时，按需授予 USB 访问权限并保持应用在前台。
4. 设备确认完成后查看更新状态。点击**传输日志**可打开本次任务记录。

可取消的传输阶段可点击**停止**。如果设备留在 IAP 升级模式，可重新连接并选择兼容文件，从头传输。BLE 用于监测和面板遥控，升级通过 USB 进行。

原厂文件、固件研究资料与历史传输记录存放在同级的 `Atorch-Load-Firmware` 仓库。通过文件检查也需要现场核对设备型号和固件适用范围。
