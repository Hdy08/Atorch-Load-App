# 界面与明暗主题

2026-11-18 的菜单、数值输入、图表文案及窄屏按钮行为见 [控件统一说明](controls-menu-20261118.md)。

应用使用 `@fluentui/react-components` 官方主题及主题工厂。默认主题选择为“跟随系统”，也可通过“应用设置 → 外观 → 主题”选择浅色或深色；已有明确的旧版主题选择会迁移保留。强调色默认读取 Windows / Android 系统颜色，也可选择预设色或系统取色器。自定义品牌色阶交给官方 `createLightTheme` / `createDarkTheme` 生成语义 token，默认 Fluent 蓝使用原版主题。中性色和状态色保持官方值。

Windows 跟随系统时独立读取原生系统应用背景色，不使用已被应用强制主题影响的 WebView 媒体查询作为唯一来源；重新选择跟随系统及窗口恢复焦点时刷新，标题栏同时恢复系统主题跟随。明暗颜色切换通过原生 View Transitions 执行约 200 ms 过渡，系统减少动态效果时直接切换；初次加载不播放主题动画。手机首次及恢复默认缩放为 75%，桌面为 100%，已有保存值继续使用。

## 样式约定

- 按钮、卡片、表格、输入框、开关和对话框使用官方组件的默认外观及其公开属性。导航按用户指定的状态显示：正常项透明，选中或悬停时采用官方悬停背景 token；不增加普通项底色。
- 页面等自有容器使用 Fluent 的语义颜色、字体和圆角 token，不写两套十六进制颜色，也不使用 `.dark` 覆盖。页面、卡片和侧栏分别取 `colorNeutralBackground2`、`colorNeutralBackground1`、`colorNeutralBackground3`。
- ECharts 保留原有曲线、缩放和导出功能，直接读取传给 `FluentProvider` 的同一主题对象。坐标文字、网格、提示框、缩放条和 PNG 背景随主题一起切换。10 个参数使用分散色相及明度的独立图表配色，预设色板包含这 10 种颜色，分别适配深浅画布且不随界面强调色改变。颜色输入框右侧提供官方图标按钮，调用系统颜色选择器；也可键盘输入十六进制颜色。配色和快捷范围操作见 [曲线配色与鼠标范围操作](chart-controls-20261118.md)。
- 用户在“曲线设置”保存的颜色仍作为显式选择保留；未自定义的曲线随主题取色，“恢复默认”重新使用当前主题色。
- `FluentProvider` 也会为对话框等 portal 根节点提供主题。视口的 flex 布局及 `min-height` 只放在 `.app`，避免弹出层改变页面尺寸。

## 页面结构

移除品牌 Logo、顶部工作空间栏、英文眉题、页面底部设备/更新时间栏、侧栏版本号与主题按钮。导航使用官方 `Nav` / `NavItem`，选中时使用对应的 Filled 图标，实时页采用 `PulseSquare` 图标。桌面侧栏四周 16 像素，展开 / 收起共用内边距与图标位置，收起时图标居中；指示条独立固定在导航项左边缘，避免与图标重叠。手机竖屏使用底栏，选中指示条位于页签底部并平滑移动，遵循系统减少动态效果设置；横屏使用同桌面的侧栏，手机页面边距仍为 16 像素。导航栏不显示分隔线。

页面只保留主标题，移除各页面标题下的介绍小字、“工作空间”标签和实时曲线副标题。实时监控顶部统一显示电压、电流、功率、电阻、电量、容量六张独立卡片，不再显示英文标签与“实时 / 等待采样”卡片页脚。统一使用官方 Card 默认 medium 尺寸，与其它卡片同为 12 像素内边距及中号圆角；读数卡片内部保留 4 像素紧凑间距，数值上方不留自动空白，高度为 80 像素。宽屏六列、中等宽度三列、手机两列。读数保留原有精度，数字按卡片宽度自适应，单位保留。原“温度与散热”合并卡片拆为 CPU 温度、MOS 温度、NTC 温度、风扇转速四张独立卡片，宽屏四列、手机两列，与顶部六张共用同一读数卡片组件、间距、标题、数值及单位配色；缺失读数显示“—”。

六张读数卡片标题与“实时曲线”标题共用 `h2` 字体样式：Fluent `fontSizeBase300`、`lineHeightBase300`、`fontWeightSemibold` 及主文字色，手机端同样使用该样式。下方数值、单位和右上角单位标识文字使用对应曲线颜色，标识底色为该色 16% 透明度的填色；自定义颜色、主题切换、刷新恢复和恢复默认时同步更新。

设备连接状态及管理入口集中在左下角；页首不再重复连接按钮、连接成功提示、蓝牙说明横条或设备概览卡。状态直接放在设备名称后，使用 `(USB)`、`(BLE)`、`(未连接)`、`(异常)`；没有设备名称时只显示 `(未连接)`，不再单列状态或原始系统错误。设备名和连接状态使用 `fontSizeBase300 / lineHeightBase300`，辅助标签使用 `fontSizeBase200 / lineHeightBase200`，管理按钮使用官方默认中号尺寸。连接状态使用 `colorStatusDangerForeground1`（未连接或异常）和 `colorStatusSuccessForeground1`（已连接）。按钮只保留连接图标，移除圆点徽章；窄屏侧栏保留图标入口，手机将连接 / 管理设备作为底栏第五个入口放在最右边，与四个导航按钮等宽、等高及对齐。删除扫描窗口通用的蓝牙靠近与 USB 线缆提示，实际扫描失败仍通过通知反馈。

Windows 使用系统原生标题栏、最小化 / 最大化 / 关闭按钮以及拖动、双击和调整尺寸行为。明暗主题同步至系统窗口，支持自定义标题栏颜色时尝试使用导航栏同色；配色接口不可用时保留系统配色，不再回退到自绘三键。页面只在原生标题栏以下滚动，标题和右上角按钮的布局框均从内容区顶部 24 像素开始；滚动条自身宽度计入页面右边距，滚动或鼠标接近右边缘时显示，空闲 1 秒后隐藏，不因显隐改变内容宽度。图表全屏仍使用原有流程。

连接窗口使用官方 `DialogActions` 的起始/结束位置区分断开操作和扫描/关闭操作；按钮文字保持单行，小屏采用组件自带的纵向动作排列。

未连接时按“应用设置 → 连接”的策略进行自动连接，可选关、优先 USB、优先 BLE、仅 USB、仅 BLE，默认优先 USB；手动管理及固件页优先取得控制权。主动断开后暂停自动连接，重新手动连接成功后恢复自动重连；应用下次启动仍可自动寻找设备。数据记录仅分“当前记录 / 历史记录”，本机记录库放在历史页，导入文件自动进入历史页。电量、容量不计算平均值，原始缺失时补算并在统计通道标记“计算”。USB 读数采用设备返回值；BLE 电阻按电压、电流计算，电量按本次连接功率积分，两者显示三位小数，切回 USB 后采用实际回读值。

原“负载控制”卡片改为仅在实时页右上角显示的固定悬浮控件。USB 从左到右为拖动手柄、模式标识、当前模式目标文本、设置图标、启停图标。手柄支持鼠标、触摸及方向键，在导航右侧的整个页面范围内移动，切换页面保留位置，重新打开应用恢复默认位置。控件及通知的默认右边缘跟随卡片内容区，通知最大宽度限制在该内容区内；实时页通知从控制器默认位置底边以下 16 像素开始，拖动后锚点不变。应用设置页通知从右上角操作按钮底边以下 16 像素开始。手机竖屏与横屏标题行均为 32 像素行高，移除多余最小高度；实时页按控制器实际尺寸保留占位，宽度足够时与标题同排，不足时仅换行一次，避免固定占位造成多余留白。CC / CV / CR / CP 分别显示“恒电流 / 恒电压 / 恒电阻 / 恒功率”，单位位于输入框内；回车校验并提交，失焦不提交，设备确认后回读。专用模式隐藏普通目标输入。启停沿用原有状态限制与启动确认，停止直接发送停止命令。其它页面隐藏控件并取消对应占位。

设置图标打开标题为“负载控制”的官方 Dialog，包含“快速设定”和“模式切换”页签。快速设定包含原有五项，并增加 MOS 与 NTC 温度上限；专用模式隐藏此页签。模式切换卡片按最小 160 像素的宽度自动排列，小屏最小宽度为 140 像素，常规桌面每行五张、手机约两张，保留 16 像素间距；仅显示左上角模式代码和标题，说明放入悬停提示；点击卡片或聚焦后按 Enter / 空格直接切换，成功后关闭弹窗。十种模式、运行状态锁定、设备回读和失败重试均保留，不再显示卡片内切换按钮、底部说明或重复的当前模式文字。关闭或 Escape 不发送命令。BLE 遥控集成到同一悬浮控制器，从左到右为手柄、蓝牙图标、SET、-、+、OK、设置图标；四键直接发送一次，OK 不再弹窗。BLE 设置只显示“蓝牙控制”页签，包含“清空电量 / 清空容量 / 清空计时”三个按钮并保留清零确认。

快速设定按“官方 Slider → 带内嵌单位的 SpinButton → 应用按钮”排列，时限使用内嵌“时 / 分”的两个 SpinButton 和一个总分钟 Slider。通过 SpinButton 官方 root 渲染槽放置单位，仅调整内部列布局；数字值不包含单位文本。滑动条使用完整连续的标准轨道，不显示分段：步进通过公开 input 槽传给原生 range 输入，保留浏览器的鼠标、触摸及键盘步进，不启用视觉分段。控件容器不足 380 像素时，将滑动条放到输入框及按钮上方占满一行，兼容手机、平板与桌面窄窗口。输入框与滑动条共享草稿，只有应用才发送命令，发送期间其它负载控件和模式切换禁用。

电流 / 电压 / 电阻的上下按钮及滑动条分别按 0.1 A / 0.1 V / 0.1 Ω 的整数倍调整，功率按 1 W；手动输入支持 0.001 A / 0.01 V / 0.01 Ω / 0.1 W。小时和分钟分别按整数步进，滑动条按总分钟 1–5999 调整。目标与保护 / 截止约束双向联动，保护不低于当前 CC / CP 目标，截止不高于当前 CV 目标。实际范围及上限见 README 参数表。精细端点可手动输入，粗调不会越过范围或采用非整数倍的端点。

实时曲线卡片独占一行，温度及风扇卡片位于下一行。左下角依次放置“暂停 / 继续”“清空”“导出”和带图标的“截图”；数据记录页左下角为“导出 CSV”“截图”。导出和截图作为一组保持左右相邻，手机窄屏时整组换行。“重置缩放”按钮靠右下角，恢复横轴和全部纵轴。无数据时保留空白坐标图，删除中央等待提示。原有“测试记录”卡片和“开始 / 停止记录”按钮移除。采样开关在原生服务控制缓存与兼容录制的追加；清空已有数据需在官方 Dialog 中确认，取消或 Escape 保留数据。清空成功后丢弃尚在返回途中的旧历史快照并重置图表缩放，不改变暂停状态。删除“可回看采样点”页脚及曲线设置、温度、电量 / 容量三个快捷入口。

实时曲线标题右侧提供 USB 1 / 2 / 5 Hz 下拉选择，文案为“1 Hz 采样”等，首次默认 1 Hz。档位保存到原生应用配置，断开、重连及重启后恢复。它与时间范围选择并列，窄屏自动换行。两者使用官方 Select，页面副标题样式排除 Select 根节点，保持下拉箭头在控件内部。BLE 隐藏 USB 采样率选择，按设备上报频率刷新。

实时与历史曲线右上角提供“真实时间 / 相对时间”，首次默认真实时间，选择保存在本机，两处共享并在重启后恢复。切换坐标种类时重置缩放，避免把毫秒时间戳当作累计时长。相对时间使用 `时:分:秒`；实时曲线从首个采样点开始累计，清空后归零。原生单调时钟扣除暂停时间，暂停同步停止计时、缓存及兼容录制追加，继续后接续；设备状态仍可读取。每行采样附带独立的 `elapsedMs`，因此切换最近时间范围、页面和缓存滚动不会将起点误移到当前第一条可见数据。历史相对时间采用采样行已有时长，或以完整数据第一行时间为起点；时间筛选不会重置起点。实时和历史浮窗的秒数都保留两位小数，例如 `00:01:02.35`。

图表浮窗与明细保留各通道的原始小数精度并补零。CSV 精度在后台解析时按列收集并随数据传输，以整份数据缓存，保留尾随零和科学计数法；USB 按原始千分之一单位显示三位，BLE 按已解析字段精度显示。计算值及平均值显示三位。统计的最小值、最大值沿用对应极值来源的原始精度，计算得到的极值显示三位；电量与容量仍无平均值。整数和小数部分采用等宽列分别对齐，不同精度的小数点也对齐，数值表头右对齐。浮窗按同一采样时刻各曲线实际屏幕 Y 坐标从上到下排列，支持多单位轴和缩放。

除 ATORCH 的 DATE 表头外，导入兼容 `DateTime` 起始元数据及 `Time(D.hh:mm:ss.ms),Voltage(V),Current(A),Power(W)` 结构。`="00:00:00.100"` 等 Excel 文本形式按纯时间字面量解析，支持可选天数与毫秒；以 DateTime 加相对时长还原真实时间，不从文件名猜起点。没有提供的通道保持空值，保留原始负电流和文件中的功率值。

实时 CSV 按当前时间范围及缩放条选区导出；历史 CSV 在时间筛选基础上进一步按图表选区裁剪。导出保留区间内所有原始行和通道，图片则按当前视图输出并排除范围条，裁去底部 18 CSS 像素的范围条区域，保留时间刻度。CSV / PNG 均使用系统保存窗口选择目录及文件名；取消返回空结果且不显示失败或成功。

真实时间中的暂停空档断开曲线及阴影，空值不计入采样统计。完整时间域以最后一个实际采样点为右端，不额外取整或延伸到采样计时器；数据不足 1 秒时只在左侧补足跨度，最新点始终贴住绘图区右边缘。范围条右端贴边时跟随新数据，离开末端后保留所选历史范围。采样统计、明细、导出共用图表选区；鼠标静止时浮窗仍显示，离开后隐藏。悬停圆点来自同一条原始采样，绘制位置随各通道坐标轴换算；显示抽稀未保留该点时也可显示，缺失或超出坐标范围的通道不绘制。鼠标绘图区拖动使用 Pointer Events 和指针捕获，按界面缩放及旋转后的物理坐标换算，移出画布后继续当前拖动，释放时恢复更新。桌面图表及坐标轴仅响应 Ctrl + 滚轮缩放，普通滚轮滚动页面；悬停单位轴时只缩放该轴，同单位曲线保持共轴，悬停横轴或绘图区时只改变时间范围。手机双指缩放相对起始手势计算，变化比例取平方根并逐帧合并更新，避免事件数量放大灵敏度。曲线区和范围条拖动期间延后绘制新数据，松开后刷新，原生采样和文件写入继续。

横向时间范围最小为 1 秒，可选择没有采样点的暂停空档，不要求范围内存在数据。纵轴平移与缩放保留当前时间范围内至少一个真实采样值；按当前每格跨度整格平移，保持比例和格数，平移后的刻度不重新套用自动刻度公式。例如 −10～10 V、每格 2 V，可直接平移为 −8～12 V。到达数据边界后反向拖动立即响应，不累计边界外的位移。Ctrl 拖动开始后，十字或上下拖动光标保持到释放、取消或失焦，即使松开 Ctrl 或移出画布也不提前恢复。所有已选参数均无有效数据时，绘图区、坐标轴及范围条禁用鼠标范围操作，使用禁用光标。详见 [曲线平移边界与最新采样点对齐](chart-pan-limits-20261118.md)。

手机纵轴刻度区支持双指捏合，只缩放手势开始时对应的单位轴，横轴及其它单位轴保持不变；绘图区双指捏合仍缩放时间范围。单指在绘图区或纵轴保持约 0.45 秒后，分别进入水平范围框选或整格纵向平移；松手提交框选。保持完成前移动约 8 像素即取消长按，普通水平滑动仍平移时间范围，普通上下滑动滚动页面。第二根手指加入、触摸取消、窗口失焦和离开图表会取消尚未提交的框选。竖屏、横屏及旋转全屏共用坐标换算。操作及验证见 [手机曲线触屏手势](chart-touch-20261118.md)。

实时与历史图表共用全部 10 项参数选择器，选项仅显示名称及曲线颜色，单位保留在坐标轴、悬浮窗与数据表中。参数栏始终为单行，官方 Overflow 根据可用宽度保留前面的选项，放不下时显示“更多”；点击在官方 Popover 中显示 / 隐藏其余复选框。全屏时参数栏与“退出全屏”并排放在顶部，使用同一份选择及保存设置；手机旋转回退中的弹层按图表的逻辑坐标定位。勾选的参数及选择顺序自动保存到本机，实时、当前记录和历史记录同步使用；切换页面、打开其它文件或重启后保留，缺少数据的通道不会被自动取消。首次默认电压、电流；损坏或无有效参数的配置恢复默认，有效参数去重并保留原顺序。温度显示顺序统一为 CPU、MOS、NTC，“探头温度”统一改为“NTC 温度”，包括温度卡片、参数选择、曲线设置和明细列。BLE 的旧“设备温度”已按用户确认并入 MOS 温度，温度卡片、曲线及设置不再提供重复入口，旧 CSV 和曲线偏好兼容迁移。所选参数按单位分组，共享 Y 轴；所有温度均共用 °C 轴，最多同时显示八种单位。单位按当前选择顺序首次出现的先后排列，前半数放左边、后半数放右边，从左到右保持同一顺序。Y 轴标签带单位，自动范围及缩放的刻度绝对值满足 0.5 × k × 10ⁿ，k、n 为整数，2 ≤ k < 20、n ≥ -1，零点合法，最多两位有效数字和一位小数。先生成精确的刻度坐标再绘制，所有单位轴的每个刻度逐一对齐同一组水平网格；最大绝对刻度达到 10 且刻度均为整数时显示整数，其余统一一位小数；同一条轴使用统一小数位数，数字按等宽字体补足前导空格，使左右两侧各轴的个位、小数点和单位分别上下对齐。Y 轴数值颜色跟随对应曲线及用户自定义颜色，温度共用轴继续使用中性色。轴顶部无单位标题。测量标签宽度分配各轴间距和图表边距，窄屏图表内部可横向滚动，页面保持无横向溢出。未知通道仍为缺失曲线，不补成零。

曲线卡片底部提供拖动手柄，支持鼠标和触摸调整图表高度，按帧合并更新并在同一次布局中同步画布尺寸，拖动时关闭页面滚动锚定，松开后保存高度。缩短已滚动页面的高卡片时保留维持视野所需的页面高度，随后随向上滚动安全回收，避免浏览器强制修改滚动位置；主容器保留稳定滚动条槽，防止滚动条出现或消失时卡片右边缘跳动。键盘上下键调整 20 像素，Shift 配合上下键调整 100 像素，Home / End 到达最小 / 最大高度。图表高度限制为 240–1000 像素，自动范围低于 520 像素优先使用 5 格，达到 520 像素使用 10 格；5 格无法同时满足精确刻度、步长限制与电流居中时统一改用 10 格。所有单位轴使用相同格数。每格仅取 1／2／5 × 10ⁿ，最低 0.1，且不超过 max(0.1, 当前可见有效数据的最大绝对值)，上限向下选择合法档位。自动范围覆盖有效数据，并保持电流零点居中；手动范围吸附到最接近且能覆盖请求范围的合法坐标；超出跨度上限时先限制跨度。手动纵轴缩放期间固定格数，保证全屏前后范围一致；重置后恢复按高度选择格数。实时和历史图表共用保存的高度，刷新后恢复。实时默认显示全部已采集数据。高卡片拖动复现见 [高卡片拖动与纵轴步长](chart-axis-steps-20261117.md)，最新刻度规则见 [精确刻度与手动继续](chart-exact-ticks-resume.md)。

设备参数中，截止电压显示两位小数，温度校准系数显示四位小数且无温度单位。温度校准是无量纲比例系数，采用原程序滑块对应的 0.5–2.0 范围；仍通过确认窗口写入设备。

“设备设置”包含“参数与维护”和“固件更新”两个页签，负责保护参数、设备显示与时限、校准、维护及升级。“应用设置”分“外观”“曲线”“记录”“连接”四个页签，页首右上角的“恢复默认”和“应用更改”仅作用于当前页签。外观页提供主题下拉、界面缩放、侧栏、强调色及页面过渡动画（平移、淡入、缩放、无，默认平移），应用后记忆选择并遵循系统减少动态效果设置；记录页提供“自动记录”卡片，可选关、跟随设备、设置阈值，默认关；开始与停止分别启用并设置时间，延迟及保持都要求条件连续满足，时间显示一位小数。保存后在重启及重连时恢复。手动暂停暂时屏蔽开始条件，手动继续仍受停止条件控制。USB / BLE 行为及旧设置迁移见 [连接与数据记录](recording.md)。曲线页为各通道显示独立设置卡片，直接编辑上下限、颜色、线宽及阴影不透明度，“恢复默认”编辑默认草稿，再通过“应用更改”保存。阴影指曲线下方同色填充，范围 0–100%，默认 0%，PNG 导出保留同样样式。相同单位的轴合并所选参数的范围，自动通道仍覆盖实际数据。实时与历史共用一份本机偏好，不再提供范围切换；旧版配置自动迁移，单个参数同时有两份配置时优先保留实时配置。图表高度同样共用，不向设备写入参数。升级进度提示也跳转至“设备设置 → 固件更新”，升级期间的锁定及确认流程保持有效。

固件页初次未选择文件时只显示“固件检查”卡片；成功检查后显示右侧“选择 USB 设备”卡片，下拉框右侧并排放置“刷新”和“刷写”。升级期间同一个按钮切换为“停止”，不可取消的烧写确认阶段禁用。升级状态依次显示阶段纯文本、铺满卡片内容宽度的进度条、`10% 1000/10000` 格式的进度，以及点击打开文件的“传输日志”按钮。已有任务切换页面后仍可查看进度与日志。CRC 标签为“CRC16”，百分比保留整数；确认窗口仅保留目标、文件、摘要及确认操作，删除重复的流程说明和记录提示。操作说明见 [USB 固件更新](usb-update.md)。
