# 界面与明暗主题

应用直接使用 `@fluentui/react-components` 的 `webLightTheme` 和 `webDarkTheme`，不修改主题对象、不另设品牌色阶。主题选择保存在本机，通过“应用设置 → 外观 → 深色主题”切换。

## 样式约定

- 按钮、卡片、表格、导航选择按钮、输入框、开关和对话框使用官方组件的默认外观及其公开属性。布局样式可以调整排列、宽度和溢出，但不覆盖组件的背景、边框、圆角、阴影、字体或交互状态。
- 页面等自有容器使用 Fluent 的语义颜色、字体和圆角 token，不写两套十六进制颜色，也不使用 `.dark` 覆盖。页面、卡片和侧栏分别取 `colorNeutralBackground2`、`colorNeutralBackground1`、`colorNeutralBackground3`。
- ECharts 保留原有曲线、缩放和导出功能，直接读取传给 `FluentProvider` 的同一主题对象。坐标文字、网格、提示框、缩放条和 PNG 背景随主题一起切换。10 个参数的默认色互不重复，预设色板包含这 10 种颜色，均来自官方主题的品牌色及调色板 token。颜色输入框右侧提供官方图标按钮，调用系统颜色选择器；也可键盘输入十六进制颜色。
- 用户在“曲线设置”保存的颜色仍作为显式选择保留；未自定义的曲线随主题取色，“恢复默认”重新使用当前主题色。
- `FluentProvider` 也会为对话框等 portal 根节点提供主题。视口的 flex 布局及 `min-height` 只放在 `.app`，避免弹出层改变页面尺寸。

## 页面结构

移除品牌 Logo、顶部工作空间栏、英文眉题、页面底部设备/更新时间栏、侧栏版本号与主题按钮。

页面只保留主标题，移除各页面标题下的介绍小字、“工作空间”标签和实时曲线副标题。实时监控顶部统一显示电压、电流、功率、电阻、累计电量、累计容量六张独立卡片，不再显示英文标签与“实时 / 等待采样”卡片页脚。统一使用官方 Card 默认 medium 尺寸，与其它卡片同为 12 像素内边距及中号圆角；读数卡片内部保留 4 像素紧凑间距，数值上方不留自动空白，高度约 80–84 像素。宽屏六列、中等宽度三列、手机两列。读数保留原有精度，数字按卡片宽度自适应，单位保留。

六张读数卡片标题与“实时曲线”标题共用 `h2` 字体样式：Fluent `fontSizeBase300`、`lineHeightBase300`、`fontWeightSemibold` 及主文字色，手机端同样使用该样式。下方数值、单位和右上角单位标识文字使用对应曲线颜色，标识底色为该色 16% 透明度的填色；自定义颜色、主题切换、刷新恢复和恢复默认时同步更新。

设备连接状态及管理入口集中在左下角；页首不再重复连接按钮、连接成功提示、蓝牙说明横条或设备概览卡。设备名和连接状态使用 `fontSizeBase300 / lineHeightBase300`，辅助标签使用 `fontSizeBase200 / lineHeightBase200`，管理按钮使用官方默认中号尺寸。连接状态使用 `colorStatusDangerForeground1`（未连接或异常）和 `colorStatusSuccessForeground1`（已连接）。按钮只保留连接图标，移除圆点徽章；窄屏侧栏保留图标入口，手机在底部导航上方显示连接状态和管理入口。详细连接错误也可在管理窗口查看。

连接窗口使用官方 `DialogActions` 的起始/结束位置区分断开操作和扫描/关闭操作；按钮文字保持单行，小屏采用组件自带的纵向动作排列。

未连接时前台自动检查 USB，未连接成功再扫描 BLE，状态文字显示当前扫描或连接阶段；手动管理及固件页优先取得控制权。数据记录仅分“当前记录 / 历史记录”，本机记录库放在历史页，导入文件自动进入历史页。累计电量、容量不计算平均值，原始缺失时补算并在统计通道标记“计算”。原始设备读数卡片仍保持设备字段的含义。

移除“测试模式”导航及独立页面，模式切换集成在实时监控的“负载控制”内。当前模式卡片内部右侧提供“切换”按钮，点击官方 Dialog 弹窗展示十种模式；内容区域在小屏内滚动，标题和关闭操作保留。成功回读后关闭弹窗并同步卡片与目标单位，失败在弹窗内提示且可以重试。关闭或 Escape 不发送设备命令；运行中或状态未确认时模式按钮禁用。BLE 继续提供面板遥控，不暴露 USB 精确模式切换。

实时曲线卡片独占一行，负载控制与温度卡片位于下一行。左下角依次放置“暂停 / 继续”“清空”“导出”和带图标的“截图”；数据记录页左下角为“导出 CSV”“截图”。导出和截图作为一组保持左右相邻，手机窄屏时整组换行。“重置缩放”按钮靠右下角，恢复横轴和全部纵轴。无数据时保留空白坐标图，删除中央等待提示。原有“测试记录”卡片和“开始 / 停止记录”按钮移除。采样开关在原生服务控制缓存与兼容录制的追加；清空已有数据需在官方 Dialog 中确认，取消或 Escape 保留数据。清空成功后丢弃尚在返回途中的旧历史快照并重置图表缩放，不改变暂停状态。删除“可回看采样点”页脚及曲线设置、温度、电量 / 容量三个快捷入口。

实时曲线标题右侧提供 USB 1 / 2 / 5 / 10 Hz 下拉选择，文案为“1 Hz 采样”等，首次默认 1 Hz。档位保存到原生应用配置，断开、重连及重启后恢复。它与时间范围选择并列，窄屏自动换行。两者使用官方 Select，页面副标题样式排除 Select 根节点，保持下拉箭头在控件内部。BLE 隐藏 USB 采样率选择，按设备上报频率刷新。

实时与历史曲线右上角提供“真实时间 / 相对时间”，首次默认真实时间，选择保存在本机，两处共享并在重启后恢复。切换坐标种类时重置缩放，避免把毫秒时间戳当作累计时长。相对时间使用 `时:分:秒`；实时曲线从首个采样点开始累计，清空后归零。原生单调时钟扣除暂停时间，暂停同步停止计时、缓存及兼容录制追加，继续后接续；设备状态仍可读取。每行采样附带独立的 `elapsedMs`，因此切换最近时间范围、页面和缓存滚动不会将起点误移到当前第一条可见数据。历史相对时间采用采样行已有时长，或以完整数据第一行时间为起点；时间筛选不会重置起点。实时和历史浮窗的秒数都保留两位小数，例如 `00:01:02.35`。

除 ATORCH 的 DATE 表头外，导入兼容 `DateTime` 起始元数据及 `Time(D.hh:mm:ss.ms),Voltage(V),Current(A),Power(W)` 结构。`="00:00:00.100"` 等 Excel 文本形式按纯时间字面量解析，支持可选天数与毫秒；以 DateTime 加相对时长还原真实时间，不从文件名猜起点。没有提供的通道保持空值，保留原始负电流和文件中的功率值。

实时 CSV 按当前时间范围及缩放条选区导出；历史 CSV 在时间筛选基础上进一步按图表选区裁剪。导出保留区间内所有原始行和通道，图片则按当前视图输出并排除范围条，裁去底部 24 CSS 像素的范围条区域，保留时间刻度。CSV / PNG 均使用系统保存窗口选择目录及文件名；取消返回空结果且不显示失败或成功。

真实时间中的暂停空档断开曲线及阴影，空值不计入采样统计。范围条右端贴边时跟随新数据，离开末端后保留所选历史范围。采样统计、明细、导出共用图表选区；鼠标静止时浮窗仍显示，离开后隐藏。悬停任一单位轴时滚轮只缩放该轴，同单位曲线保持共轴；横轴悬停滚轮只改变时间范围。曲线区和范围条拖动期间延后绘制新数据，松开后刷新，原生采样和文件写入继续。

实时与历史图表共用全部 10 项参数选择器，选项带名称、单位及曲线颜色。勾选的参数及选择顺序自动保存到本机，实时、当前记录和历史记录同步使用；切换页面、打开其它文件或重启后保留，缺少数据的通道不会被自动取消。首次默认电压、电流；损坏或无有效参数的配置恢复默认，有效参数去重并保留原顺序。BLE 的旧“设备温度”已按用户确认并入 MOS 温度，温度卡片、曲线及设置不再提供重复入口，旧 CSV 和曲线偏好兼容迁移。所选参数按单位分组，共享 Y 轴；所有温度均共用 °C 轴，最多同时显示八种单位。单位按当前选择顺序首次出现的先后排列，前半数放左边、后半数放右边，从左到右保持同一顺序。Y 轴标签带单位，默认保留一位小数，Y 轴顶部最大刻度达到 10 时显示整数；同一条轴使用统一小数位数，数字按等宽字体补足前导空格，使左右两侧各轴的个位、小数点和单位分别上下对齐。Y 轴数值颜色跟随对应曲线及用户自定义颜色，温度共用轴继续使用中性色。轴顶部无单位标题。测量标签宽度分配各轴间距和图表边距，窄屏图表内部可横向滚动，页面保持无横向溢出。未知通道仍为缺失曲线，不补成零。

曲线卡片底部提供拖动手柄，支持鼠标和触摸调整图表高度；键盘上下键调整 20 像素，Shift 配合上下键调整 100 像素，Home / End 到达最小 / 最大高度。图表高度限制为 240–1000 像素，低于 520 像素分为 5 格，达到 520 像素分为 10 格；所有单位轴使用相同格数。实时和历史图表共用保存的高度，刷新后恢复。实时默认显示全部已采集数据。自动范围选取易读的步长、覆盖有效数据，并保持电流零点居中；用户填写的完整上下限继续优先使用。

设备参数中，截止电压显示两位小数，温度校准系数显示四位小数且无温度单位。温度校准是无量纲比例系数，采用原程序滑块对应的 0.5–2.0 范围；仍通过确认窗口写入设备。

“设备设置”包含“参数与维护”和“固件更新”两个页签，负责保护参数、设备显示与时限、校准、维护及升级。“应用设置”分“外观”“曲线”两个页签。外观页提供主题开关；曲线页为各通道显示独立设置卡片，直接编辑上下限、颜色、线宽及阴影不透明度，通过“应用更改”或“恢复默认”保存。阴影指曲线下方同色填充，范围 0–100%，默认 0%，PNG 导出保留同样样式。相同单位的轴合并所选参数的范围，自动通道仍覆盖实际数据。实时与历史共用一份本机偏好，不再提供范围切换；旧版配置自动迁移，单个参数同时有两份配置时优先保留实时配置。图表高度同样共用，不向设备写入参数。升级进度提示也跳转至“设备设置 → 固件更新”，升级期间的锁定及确认流程保持有效。

## 验证

```powershell
npm run build
npm test
npm run test:ui
```

`tests/ui/themes.spec.ts` 对比两套官方主题的全部 token、按钮正常/悬停/禁用状态、连接文字颜色及字号、图表颜色及实际导出 PNG 的背景，并检查主题和曲线设置在刷新后保留。布局检查覆盖 390 / 768 / 1440 / 1920 像素下的所有页面及应用曲线页签，检查六卡高度、宽屏同排、曲线独占整行和记录按钮位置。多轴检查实际读取 ECharts 渲染的标签包围盒，核对八条轴全部可见、补零 / 单位、选择顺序、标签不重叠或裁切、温度共享轴及手机图表内滚动。

`artifacts/ui-multi-axis/` 为本轮桌面 / 手机宽度预览；`artifacts/ui-compact/`、`artifacts/fluent-themes/` 保留此前截图。均使用明确标识的界面测试数据，不代表新的设备实测。
