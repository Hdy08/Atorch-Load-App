# 应用设置、固定边距与手机系统栏（2026-11-17）

本轮实现用户的应用外观、连接、设置提交、标题栏与手机系统栏调整。基于当前工作区继续修改，没有复位旧的功能、固件或协议工作，没有刷写或控制实体负载。

## 页面与设置行为

桌面页面边距固定 24 物理 CSS 像素，手机固定 16；移除 1740 像素最大宽度产生的自动留白，窗口扩大、缩小及界面缩放时保持对应设备的边距。桌面窄窗口可使用底部导航布局，但边距仍为桌面的 24。手机横屏仍使用手机边距与底栏。页面滚动条计入右边距，不额外增加空白。原有同组小卡片 12、普通网格 16 的逻辑间距保留，随界面缩放一起缩放。

应用设置分为外观、曲线、记录、连接。页首右上方两个按钮通过原生 HTML 表单关联当前页签：

- “恢复默认”仅将当前页签的编辑内容恢复为默认草稿。
- “应用更改”仅校验、保存并启用当前页签的设置。
- 切换页签保留当前应用设置页面内未应用的输入；导航离开应用设置后，重新进入以已保存内容为准。
- 曲线页底部重复按钮移除。曲线与记录不再在编辑时自动保存或立即调用设备服务。
- 设置的成功提示仍使用悬浮通知。

外观默认值：主题跟随系统、界面缩放 100%、侧栏自动、页面过渡平移、强调色跟随系统。缩放范围为 50%–200%，通过连续滑动条及带内嵌 % 单位的数字输入框编辑，点击应用后生效。整个内容、弹窗和通知一同缩放，桌面标题栏保留正常尺寸。浮动控件及通知以同一物理坐标测量后转换为缩放坐标，保持与内容区对齐；曲线以实际缩放后的像素密度绘制，拖动高度及全屏尺寸也换算比例。

导航替换为 Fluent 2 官方 `Nav` / `NavItem`，保留组件原生选中指示条、鼠标和键盘交互、Filled / Regular 图标切换；页面与设备管理共用 Navigation 上下文。侧栏选项为自动、始终展开、始终收起。自动在可用逻辑宽度 1200 以下收起；显式展开 / 收起不受桌面窗口宽度影响。手机布局使用底部导航，连接 / 管理设备按钮为最右第五项，与其它四项等宽等高。

主题下拉为跟随系统、浅色、深色。首次使用跟随系统，旧版已有明暗主题选择迁移保留；“恢复默认”回到跟随系统。系统明暗变化会更新页面、图表和 Windows 标题栏。强调色默认通过 Windows `UISettings.GetColorValue(Accent)` / Android 系统强调色资源读取；首次启动、窗口重获焦点和系统明暗变化时刷新。提供十个预设、十六进制输入及取色器，自定义色经完整品牌色阶交给 Fluent 官方主题工厂；过浅颜色调整深度以保留按钮白字对比，中性色和状态色不覆盖。

标题栏从立即按下就交给系统拖动，改为按下并移动至少 4 像素后开始拖动，避免吞掉第二次点击。双击切换最大化 / 还原，按钮和拖动继续保留。

## 自动连接

连接页可选关、优先 USB、优先 BLE、仅 USB、仅 BLE，默认优先 USB，保存在 `atorch-auto-connect`。

优先策略在首选传输无可用设备或连接失败时尝试另一种；优先 USB 保留 BLE 扫描结束后再次检查 USB 的行为。“仅”策略不扫描或请求另一种传输的权限。修改策略时先取消并等待旧扫描结束。关不影响已经建立的连接，也不进行后台扫描。用户主动断开仍暂停本次应用会话的自动连接，直到重新手动连接成功；切换策略不会绕过这一状态。固件、手动管理和不可见页面继续具有原有优先级。

记录默认“根据负载状态自动启停记录”关闭；恢复默认也只编辑当前记录设置，应用后才调用原有服务保存。

## Android 安全区域与状态栏

保留禁用 WebView 双指页面缩放。原生 Activity 对系统栏、显示缺口及键盘的 WindowInsets 设置内容容器内边距，避免 WebView 在状态栏下面绘制；消费对应 Insets 后避免重复分发。

普通横屏通过系统 InsetsController 隐藏状态栏，回到竖屏恢复。应用从后台恢复且仍横屏时重新应用隐藏状态。曲线全屏继续使用原有横屏 / 隐藏系统栏流程，退出后恢复对应状态；Insets 变化时内容重新测量，不为隐藏的状态栏残留高度。
