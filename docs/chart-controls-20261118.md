# 曲线配色与鼠标范围操作

## 配色

曲线默认色和预设色采用独立于界面强调色的十色方案，分散色相与明度，分别适配深色和浅色画布。电压为蓝色、电流为绿色、功率为橙色、电阻为紫色、电量为青色、容量为红色，CPU／MOS／NTC 温度及风扇转速使用其余四种颜色。预设不再将相近的品牌紫、调色板紫或两种浅黄色同时作为不同通道的默认色。

已有自定义颜色继续保留。未自定义通道的曲线、读数卡片、单位标识和参数色点同步使用新颜色。温度共用纵轴的文字仍使用主题文字色。系统强调色仍作用于 Fluent 控件和导航。

十种颜色逐对检查 OKLab 距离至少 0.10，且与对应画布的对比度至少 3:1。这是对默认色区分度和细线可见性的回归约束，不代表所有色觉条件下都能仅依靠颜色区分全部参数。

## 鼠标操作

| 区域           | 操作                | 结果                                             |
| -------------- | ------------------- | ------------------------------------------------ |
| 绘图区         | 普通左键拖动        | 平移当前水平时间范围                             |
| 绘图区         | Ctrl + 左键拖动     | 十字指针与整高选框，松开后使用框选的水平时间范围 |
| 纵轴刻度区     | Ctrl + 左键上下拖动 | 按整格平移该单位轴，保持跨度及每格间隔           |
| 绘图区／时间轴 | Ctrl + 滚轮         | 缩放水平时间范围                                 |
| 纵轴刻度区     | Ctrl + 滚轮         | 每次直接选择下一档合法纵轴比例                   |
| 图表区域       | 普通滚轮            | 滚动页面                                         |
| 下方水平范围条 | 拖动选区或两端手柄  | 保留原有选区平移和端点调整                       |

主图框选支持向左或向右拖动，并限制在绘图区内；竖向位移不修改纵轴。小于 4 像素的拖动不建立范围。Esc、取消指针或窗口失焦会取消未提交的选框。按住 Ctrl 时可在不移动鼠标的情况下切换指针。实时、当前记录、历史记录、全屏和界面缩放使用同一套操作。

下方范围条关闭原有的十字指针和空白区域框选。范围条与绘图区底边的间距由 39 减为 26 个界面像素；时间刻度文字仍完整显示。PNG 导出同步调整裁切边界，保留时间刻度且不包含范围条。

## 精确刻度

纵轴滚轮不再先累积不可见的小幅范围变化，再等待吸附跨档；每次从已显示的实际坐标直接选择下一档合法范围。到达最细或最大允许比例后保持不变，反向滚动立即离开边界，不积累隐藏的缩放量。连续手势固定作用于原单位轴，避免刻度文字宽度变化后命中相邻轴。

框选和平移仍遵守 [精确刻度规则](chart-exact-ticks-resume.md)。纵轴平移使用整格位移，全部刻度精确、共用相同水平网格。若请求位置不满足既有整数公式，则吸附到最近合法的整格位置。缩放选择能够保留鼠标所指坐标值的下一档合法范围；没有更细合法范围时即为当前缩放边界。

## 验证

单元回归覆盖单次滚轮跨档、缩放边界后的反向响应、跳过非法档位、正负及大小幅值、保留指向值、整格平移、颜色间距及深浅画布对比度。

界面回归覆盖主图双向框选、Ctrl 指针切换、取消框选、左右纵轴拖动期间刷新、范围条禁用框选、单次滚轮响应、75% 界面缩放、当前记录及全屏。25 万点 CSV 中继续验证范围框选、单位像素抽稀、精确采样回看及完整原始数据导出。原有断档悬停、高度拖动、采样继续、精度和全屏用例一并运行。

构建与验证记录位于 `artifacts/chart-controls-20261118/`。界面验证使用浏览器和模拟 IPC，本轮未进行设备刷写或手机实机操作。
