## 本轮完成的数据与曲线流程

2026-11-12 新增本机记录库，读取磁盘文件，支持应用重启后回看。8,001 点自动测试验证不会按实时缓存的 7,200 点截断；Windows 原生窗口实际载入现有 1,041 点 CSV。正在录制的文件显示状态并禁止作为完整文件打开，后端也执行同样的检查。文件名不能提交路径，载入上限为 50 MB。

实时采集、磁盘记录与导入 CSV 共用数据回看工具。开始 / 结束时间用于图表、统计、明细和导出；无效范围会阻止导出。图表缩放保留在图表内，需要裁剪文件时使用时间筛选。统计按原始点计算，各通道缺失值不参与计算，有效 0 与负数保留；不推算未提供的累计电量。

曲线偏好在“应用设置 → 曲线”共用保存，每项参数可设置上下限、10 种官方 Fluent 预设色或十六进制颜色、系统取色器、0.5–3.0 线宽及默认 0% 的阴影不透明度。10 个参数默认色各不相同；原 BLE 设备温度按用户确认并入 MOS，旧 CSV 和偏好兼容迁移。实时与历史共用这些偏好及保存的图表高度，旧配置自动迁移，冲突时优先保留该参数的实时配置。实时默认显示全部数据，两处均可选择全部测量参数；同单位共用 Y 轴，按所选顺序均分在图表两侧，所有单位轴同时显示。轴标签默认一位小数，Y 轴顶部最大刻度达到 10 时为整数，等宽字体按数位对齐并带单位。曲线底部手柄支持鼠标、触摸和键盘调整高度，按高度自动切换 5 / 10 格。BLE 未确认的字段仍为缺失曲线。曲线卡片独占整行，暂停 / 清空 / 导出移到左下角，删除旧快捷入口、采样点页脚与测试记录卡片。窄屏使用图表内部横向滚动。缩放位置在新快照到来时保留，可重置；图表使用采样绘制，统计与 CSV 使用原始数据。

USB 档位支持 1 / 2 / 5 / 10 Hz，首次默认 1 Hz 并在原生配置中记忆；BLE 按设备上报频率采集。实时与历史曲线右上角可选择真实 / 相对时间，首次默认真实时间，选择共享并记忆。实时相对时间从首个采样点的 0 开始，暂停同步停止原生计时、缓存及兼容录制追加，清空后重置。继续时扣除暂停间隔，CSV 保留真实时间戳；两种浮窗时间均显示到秒后两位小数。外部 CSV 兼容 DateTime 起始元数据和 Time(D.hh:mm:ss.ms) 相对时间列，支持 Excel 文本、天数和毫秒，保留负电流及原始功率。读数卡片统一采用默认 medium Card，与其它卡片同为 12 像素内边距，内容仍保持紧凑。

后续按用户要求调整默认坐标：电压等非负通道从 0 起，电流按数据最大绝对值对称显示，零点位于中间；全零 / 空数据使用有限的默认范围。负温度等有效负值保留。手动填写的范围优先，“恢复默认”重新使用上述规则。

Windows 和 Android 均走原生 PNG 保存路径。Android CSV 与 PNG 共用系统文档保存回调，并在独立文件线程写入；本轮已实际写入下载目录、拉回检查 PNG 签名 / 尺寸及 CSV 内容，保存期间蓝牙持续采集。具体结果与安装包校验值见 `validation.md`。

## 阶段控制、专用读数与固件握手

已沿 `MainDialog::buttonClicked → 0x40e080 → 0x405150` 核准模式入口：`47–50` 对应模式值 `0–9`，完整报文和函数地址见 `protocol.md`。Windows 原生界面已实际进入 10 个模式并恢复 CC，各模式目标与共享参数保留。模式选择、带模式上下文的目标和启动在执行前重新查询设备；成功 ACK 不能代替模式回读。

当前入口为“实时监控 → 负载控制”模式卡片右侧的“切换”按钮，使用弹窗选择模式，移除独立的测试模式导航。只有回读确认后关闭弹窗；失败提示留在弹窗中，取消不会发送命令。UI 夹具回归覆盖十种切换、运行中禁用、失败重试、目标单位、关闭及 390 / 768 / 1440 像素布局。

2026-11-13 继续追踪 `CDPopTips` 回调、显示逻辑及 Qt 字面文本，核准返回 = 1、继续上一轮放电 = 2、确认 = 5。“清除数据并开始新一轮放电”在提示类型 2 为 2，在类型 3 为 3，不能固定为一个指令值。提示码来自 `05` 偏移 54 的十进制十位 / 个位，只表示提示类型与当前选项。界面按提示生成动作并确认，后端重新读取模式及提示上下文，过期操作拒绝发送，单独 ACK 不确认完成。具体地址、映射及尚未实测的边界见 `special-tests.md`。

IR / POWER / CABLE / CDC / CDCDC 接入原应用启停命令，启动前有确认，循环模式还校验电池参数。专用视图使用已核准的 `05` 字段，记录运行中最后数据、停止数据和本次采集峰值，未知的停止原因、最终结果与判定不填造。连接中途开始采集时标注记录不完整；最多 100 条本次连接内的停止记录可导出 CSV。

固件逻辑支持 AA 握手、BB 就绪、CC 数据、DD 序号确认、EE 传输结束、FF 完成、11 拒绝，以及 CRC16、尾块和超时 / 取消。BW150 的 643,072 字节 / 11,088 块及 BW600 的 712,704 字节 / 12,288 块已分别在 Windows 和 Android 原生应用中完成离线预演，监测保持连接。后续完成官方实机抓包，核准满块 USB 仅缺 CRC 高字节、数据全部存在；Windows / Android 新应用已实际写入该 BW150 文件，完成 EE / FF 和正常应用回读，Android 从 IAP 重新传输恢复也通过。硬件入口严格限制摘要和接口，详见 `firmware.md`。

早先的专用测试验收仅进行停止状态下的模式切换、读数与 BLE 录制，未执行专用启动、阶段写入或清除。后续固件任务已完成官方及 Windows / Android 新应用刷写；剩余工作以完整专用测试的设备行为、CDxn 参数、故意断电恢复及其他设备组合为主。
