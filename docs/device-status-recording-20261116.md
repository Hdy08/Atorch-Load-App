# 设备状态、温度卡片与记录设置（2026-11-16）

## 界面和连接行为

- 设备名称后直接显示 `(USB)`、`(BLE)`、`(未连接)` 或 `(异常)`。已连接使用 Fluent 成功色，未连接和异常使用危险色。没有设备名称时只显示 `(未连接)`。
- 删除单独的连接状态行、侧栏原始系统错误，以及扫描窗口中通用的蓝牙靠近、其它应用占用和 USB 线缆供电提示。
- 点击“断开设备”后暂停本次会话的自动扫描和连接。关闭管理窗口、重新扫描、切换页面不会恢复自动连接；手动连接成功后恢复意外断线重连。重新启动应用仍按 USB 优先、BLE 其次寻找设备。
- CPU 温度、探头温度、MOS 温度和风扇拆为四张独立卡片，两列排列。它们与顶部六张电气读数卡片共用组件、80 像素高度、标题样式、内边距和曲线配色；未知通道继续显示“—”。
- Windows 标题栏随导航栏同步使用 Fluent 的背景色与文字色。Windows 11 使用原生标题栏颜色接口；Windows 10 不支持该接口时使用同色客户端标题栏，提供拖动、最大化、还原、最小化和关闭操作。

## 记录开关

“应用设置”增加“记录”页签，提供“根据负载状态自动启停记录”开关，默认关闭。原生 `sampling.json` 同时保存 `usbSampleRateHz` 和 `autoRecordOnLoad`，修改任一项均保留另一项。旧配置缺少开关时按关闭处理，重连和重启后恢复保存值。

- 关闭：负载状态变化不再覆盖手动采样选择，“暂停 / 继续”控制采样、有效计时及 CSV 追加；关闭开关本身保留当前采样状态。
- 开启：USB 首次有效运行状态及之后的状态变化控制采样与记录；刚开启时也与当前已知运行状态同步一次。连续相同状态报文保留手动选择。
- BLE 未核准负载运行标志，仍由“暂停 / 继续”控制。开关不模拟未知状态，也不向设备发送启停、目标值或面板按键命令。
- 配置落盘失败时不改变内存中的开关值；固件升级期间禁止修改。
