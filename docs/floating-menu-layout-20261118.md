# 悬浮控制器与菜单布局（2026-11-18）

悬浮控制器中的模式名称左右使用相同的 8px 间距，目标值输入框固定为 120px 的逻辑宽度。提高该控件宽度规则的选择器优先级，避免通用数值输入框的 `width: 100%` 再次将其撑宽。移除悬浮输入框额外的横向内边距，使上下微调按钮到右边框的距离与其它标准数值输入框一致。

未拖动的控制器直接以页面内容区右边缘为锚点，宽度测量不再参与默认横向定位。返回实时页时控制器不会从右侧移入；拖动后的坐标、边界限制、通知位置和重新打开应用后恢复默认位置的行为保持兼容。页面内容仍保留用户选择的过渡动画。

点击悬浮目标值的上下微调按钮后，焦点保持在数值输入区，可直接按 Enter 确认。微调只修改草稿；按 Enter 才提交一次目标值，不启停负载。到达范围边界、微调按钮变为禁用时，输入区仍保有焦点。其它数值输入框继续使用原有行为。

手动输入后再微调时，以最新草稿和实际按键方向计算步进，避免 Fluent 内部旧编辑缓存使增加键反向减小数值。输入框失焦和 Enter 提交不会被当成微调操作。

所有单选菜单使用 Fluent 定位的目标宽度匹配，并移除弹层的默认最小宽度。弹层尽量与触发按钮等宽；视口不足时受可用空间限制，长选项可换行。按钮继续按最长选项预留宽度并左对齐，弹层不参与上方工具栏布局。选中标记、方向键操作、Escape 关闭及焦点恢复保留。

修正卡片标题区域的文字选择器，排除带 `hidden` 属性的元素。Fluent 菜单的隐藏 Portal 占位节点不再被 `display: block` 覆盖，打开菜单时不会增加工具栏的 flex 间距。

安装包和验证结果归档在 `artifacts/floating-menu-layout-20261118`。本轮 UI 验证使用浏览器及模拟设备接口，没有对 BW150 执行操作。
