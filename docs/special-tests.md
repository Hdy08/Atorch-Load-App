# 专用测试、阶段控制与结果记录

更新：2026-11-13。适用证据为用户提供的 `Load_Application.exe` 与 BW150 V1.1.0。原程序散列见 `protocol.md`。Windows 已核对模式 4–9 的读取，启动 / 阶段写入仅完成代码、模拟传输与 UI 验证，尚未在真实负载上执行。

## 阶段提示的来源

原程序 `0x43b254–0x43b28c` 将 USB `05` 偏移 54 按十进制除以 10、取余，保存为提示类型和当前选项。偏移 53 为独立的原始状态码。`0x405ab0–0x405b2a` 只在模式 7 / 8、状态非零、提示类型非零时打开 `CDPopTips`。这些值不能证明当前处于充电或放电，也未提供可靠的结束原因。

`CDPopTipsSendData_Slot`（`0x411630`）构造 `55 05 地址 35 动作 00 00 00 EE FF`，补零到 64 字节。`0x44d0d0` 根据提示类型控制按钮：类型 2 隐藏继续按钮，类型 3 显示继续按钮。Qt 文本与回调交叉核对后得到：

| 提示类型 | 界面动作                 | 动作值 | 原程序证据                                            |
| -------- | ------------------------ | ------ | ----------------------------------------------------- |
| 2 / 3    | 返回                     | 1      | `Btn1` 回调 `0x44d740`；文本 `0x46a83b`               |
| 3        | 继续上一轮放电           | 2      | `Btn2` 回调 `0x44d760`；文本 `0x46a896`               |
| 2        | 清除数据并开始新一轮放电 | 2      | `Btn3` 回调 `0x44d780`，继续按钮隐藏；文本 `0x46a94f` |
| 3        | 清除数据并开始新一轮放电 | 3      | 同一回调，继续按钮显示                                |
| 2 / 3    | 确认                     | 5      | `BtnOK` 回调 `0x44d7b0`                               |

前端仅使用后端针对当前提示返回的动作。未知提示保留原始码、不给出猜测的按钮；CDxn（模式 9）不套用 CDC / CDCDC 提示规则。

## 执行与确认

每次阶段操作携带确认时的 `expectedMode` 和 `expectedPrompt { status, code }`。后端先主动读取新的 `03` / `05`，核对模式、状态码、完整提示码和允许的动作。上下文变化或读不到最新状态时不发 `35`；除返回外，还检查循环设置的电流与电压有效，充满电压高于截止电压。

写入仅发送一次，随后查询回读。当前规则要求状态码变为 0 且 USB 提示字段仍存在，继续 / 新放电还要求运行状态为真。返回 / 确认不强制运行。单独成功 ACK 不计为阶段完成，超时不自动重发清除或启动动作。以上为新应用的保守确认规则，仍需真实阶段操作验收。

原程序普通启停槽 `0x41b620` 使用 `25 01 / 00`，没有按专用模式排除。应用为 IR / POWER / CABLE / CDC / CDCDC 提供“启动专用测试”确认；CDC / CDCDC 有待处理提示时必须先处理提示。未知的 IR / POWER / CABLE 普通目标不显示、不写入。CDxn 的次数与启动参数尚未核准，继续在面板启动。

## 专用结果的范围

没有发现可核准的独立专用结果帧，当前统一使用 USB `05`：电压、电流、功率、电阻（偏移 20，Ω）、电量（24，Wh）、容量（28，mAh）、运行状态、原始状态码与提示码。负数、有效 0 和未知值分别保留。

同一模式下观察到停止 → 运行时记录开始时间；观察到运行 → 停止时生成停止记录，分别保存最后一个运行读数与停止读数，并记录本次采集的功率 / 绝对电流峰值。采集中途连接时不补造开始时间，界面标明记录不完整。模式切换、断线和普通模式不生成完成记录。

峰值是本应用采样范围内观察值，不表示设备内部的最大值。停止时电阻即使为 0 也原样保存，运行中最后电阻也不直接标为“最终内阻”。停止原因、充放电阶段、合格判定及设备内部测试报告仍未解析。

记录在本次连接内保留最多 100 条，重连会清除；可通过原生文件保存导出 CSV。需要完整时间曲线时，另行开启连续采样记录。BLE 缺少这些 USB 字段和模式上下文，当前不生成专用结果或开放阶段控制。
