# 连接与数据记录

## 自动连接

前台应用首次读取原生连接状态后，等待约 1.5 秒开始寻找设备。每轮先枚举 USB 并依次尝试兼容设备；未连接成功再扫描 BLE。BLE 扫描结束后重新枚举 USB，优先使用扫描期间插入的 USB，否则尝试发现的 BLE。已连接时保持当前通道；意外断线后重新进入自动寻找流程。用户主动断开连接时立即暂停自动寻找，关闭管理窗口或重新扫描也不会自动连接；手动连接成功后恢复意外断线重连。该暂停只影响本次应用会话，下次启动仍自动寻找。

每轮结束后等待 5 秒再尝试，失败设备路径冷却 30 秒。首次缺少 BLE 权限时可请求一次系统授权；拒绝后本轮应用生命周期内不反复弹窗，仍检查 USB。蓝牙关闭、系统定位要求未满足等情况等下轮重新检查。手动管理窗口、其它应用任务、Root 角色切换、固件页面及后台状态让出自动扫描；开始手动扫描前先取消并等待自动扫描结束，迟到结果不能触发连接。IAP 升级接口不会自动连接为普通监测设备。

自动连接只建立监测连接，不发送启停、目标值、按键或累计清零命令。Root USB-C 直连仍需用户在管理窗口启用。

## 自动记录

记录在 Rust 设备线程中写入应用数据目录 `recordings/`，每个有效点落盘刷新，不依赖 WebView 的刷新频率。“应用设置 → 记录”的卡片标题为“自动记录”，模式下拉提供“关 / 跟随设备 / 设置阈值”，默认关。页首“恢复默认”编辑当前页签草稿，“应用更改”才保存；设置和 USB 采样率分别保存到原生配置，重连及重启后恢复。旧版已启用的自动记录开关迁移为“跟随设备”，旧版关闭或无配置迁移为关。

| 模式       | 开始条件                                   | 停止条件                                   | 适用连接                     |
| ---------- | ------------------------------------------ | ------------------------------------------ | ---------------------------- |
| 关（默认） | 手动继续                                   | 手动暂停                                   | USB / BLE                    |
| 跟随设备   | “启动时开始”开关及独立延迟                 | “关闭时停止”开关及独立延迟                 | USB 的已核准运行标志         |
| 设置阈值   | “开始阈值”开关、参数、比较、数值及保持时间 | “停止阈值”开关、参数、比较、数值及保持时间 | USB / BLE 的电压、电流、功率 |

跟随设备的两项开关默认开启，阈值的两项开关默认关闭。阈值参数可选电压、电流、功率，比较可选小于、大于，数值单位随参数显示；比较为严格不等，等于阈值视为不满足。负电流等有符号阈值可正常使用。BLE 未核准运行标志，不推断负载启停；需要自动控制记录时可使用阈值。

设备页标为“延迟”、阈值页标为“保持”，**实际行为均为连续保持**：从首次观察到条件满足开始，只有条件持续满足至指定时长才触发；期间任一有效读数不满足即清零，下次满足重新计时。开始与停止分别计时，默认显示 `0.0 s`，按 `0.1 s` 调整，保存时只接受非负且最多一位小数的时间。计时使用原生单调时钟，在新遥测到达时判定，因此触发时刻受设备上报 / USB 查询间隔影响。记录暂停时仍接收遥测并判定条件。

启用开始条件后，新连接先等待开始条件成熟。每项条件持续满足期间只触发一次，恢复不满足后重新就绪；同一报文内开始、停止同时成熟时停止优先。**手动暂停暂时屏蔽开始条件**，直到观察到开始条件不满足才解除屏蔽，再次满足后重新保持计时。**自动暂停后可以手动继续**：已触发的停止条件在持续满足期间不会因手动继续而重复触发；恢复不满足后重新就绪，再次满足并完成保持仍会自动暂停。尚未完成保持的停止条件继续计时，手动继续不清零或屏蔽它。关闭自动记录保留当前手动暂停 / 继续状态。修改这些设置只控制本机采样与文件追加，不向设备发送启停或参数命令。

采样开启时缓存和自动 CSV 同步追加，暂停时二者均停止追加，有效时长也停止累计；恢复后续写同一个文件。清空已有数据仍需确认；成功后结束当前自动文件并重置缓存和计时，下次有效采集新建文件。自动文件保留在原目录，**不自动加入本机记录库**。断开时完成当前文件。写入失败单独显示记录错误，设备监测与控制继续可用；后续有效的继续采样会尝试恢复记录。

自动文件追加 `ELAPSED_MS,SEGMENT_ID` 列，记录排除暂停的单调有效时长及采样分段。当前缓存亦保留分段；导出存在时间元数据时带上这两列，重新导入后仍保留暂停边界。旧 CSV 及原有兼容录制接口继续可读。升级确认时，只有负载已确认停止且记录暂停，才会先保存关闭记录再独占 USB；仍在写入时禁止升级。

## 当前与历史

“数据记录”仅有“当前记录”和“历史记录”两个页签。当前记录使用本次连接的实时缓存（最近 7,200 点）；历史记录通过系统文件窗口导入外部 CSV，导入成功后切换到该文件。

本机记录库仅登记**手动导入及成功导出的 CSV**，不扫描自动记录目录。索引位于应用配置目录的 `record-library.json`，只保存文件路径、名称、大小及修改时间，不复制 CSV 或存储采样内容。重复导入同一路径更新一条记录；不同路径的同名文件分开显示。取消文件窗口、解析失败或取消导出不登记记录。Windows 保存完整文件路径；Android 使用系统 `ACTION_OPEN_DOCUMENT` / `ACTION_CREATE_DOCUMENT` 返回的 URI，并持久保留读取授权，供重启后打开。浏览器预览的普通文件输入只提供临时查看；持久记录库使用原生应用。

记录左侧可勾选，右上角“删除记录”只更新索引，绝不删除或修改磁盘 CSV，也不删除 Android 文档。删除正在查看的导入记录或库内记录后，同步清空其曲线、统计、明细与选区，并禁用导出和截图；删除其他记录保留当前视图，本次实时缓存也不清空。文件被移动、删除或读取权限被撤销时会明确报错，可重新导入更新引用。单份文件超过 50 MB 会整体拒绝导入，不以截断方式载入。

电量与容量不计算平均值，其统计平均值栏显示“—”。已有的有效累计值，包括零值，直接保留。缺失项在整份按时间排序的记录上补算：

- 电量：`Wh += (|P前| + |P后|) / 2 × Δt(ms) / 3,600,000`。
- 容量：`mAh += (|I前| + |I后|) / 2 × Δt(ms) / 3,600`。

首点从零开始，后续原始累计值可重新锚定缺失区间。优先使用 `elapsedMs` / CSV `ELAPSED_MS` 的间隔，否则使用真实时间差；重复时间不增加累计值，倒退的有效时长不产生负积分。功率和电流自身保留符号，仅累计量取绝对值，兼容充电负电流文件。统计使用 `电量 / Wh (计算)`、`容量 / mAh (计算)` 标注，删去标题下的积分说明。积分累加保留内部精度；曲线浮窗最多 4 位小数，统计和明细最多 3 位；CSV 导出保留原始测量值与积分内部精度，避免很小的累计值被舍入为零。

图表缩放发生在补算之后，范围变化不会重置累计起点。移除开始 / 结束日期输入行，采样统计、明细与导出统一使用图表选区；选区落在空档时有效点数为零，均值等显示“—”，不能导出虚构采样。导出保存所选范围的全部采样点及补算的累计数值，原文件不修改。CSV 仍使用真实时间戳；曲线可切换真实 / 相对时间并共享记忆设置。

纵轴每格跨度只取 1／2／5 × 10ⁿ，最低 0.1，最高不超过 max(0.1, 当前可见采样的最大绝对值)，并向下取合法档位。共享单位从所有已选通道计算，选区变化后使用该范围的原始数据更新；大 CSV 使用已有索引查询极值。刻度值按整数半十进制公式生成，最多两位有效数字和一位小数，数值及绘制位置都精确对齐同一组水平网格。自动范围优先按高度使用 5／10 格，无法同时满足精确值与电流居中时统一使用 10 格；自定义范围和手动缩放吸附到合法坐标，手动缩放期间固定格数以保留全屏范围，重置后恢复自动选择。详见 [精确刻度与手动继续](chart-exact-ticks-resume.md)。大文件视窗补充细节时保留范围条当前采用的百分比或数值范围，避免更新显示点后短暂恢复全部数据。

采样明细默认每页 10 条，可在右上角选择 10 / 20 / 50 / 100 条，设置保存在本机并用于当前与历史记录。选择器右侧输入页码后按 Enter 或移出输入框即可跳转，超出范围时限制到首页或末页。明细维持最新在前；分页仅影响表格，不截断曲线、统计或导出的采样点。

真实时间曲线在采样分段变化、有效时长揭示暂停间隔，或旧文件存在明显采样空档时断开线条与阴影，不补零，不插值。分段标记只产生图表中的空值，不进入统计、积分或 CSV。整个断档区间不显示悬停虚线、浮窗、圆点或悬停时间标签，恢复至有效采样区间后重新显示，普通时间网格仍保留。相对时间仍扣除暂停间隔。完整时间域的右端就是最后一个实际采样点，不延伸到采样计时器或取整后的未来刻度；不足 1 秒时只在左侧补足范围。范围右端保持最右边时随最新数据更新，左端保留选择的时间；右端离开末端时锁定所选历史区间。

绘图区框选、滚轮、双指及范围条调整统一保留至少 1 秒的时间跨度，允许选择完全没有采样点的暂停区间。纵轴平移和缩放另行约束：当前时间范围中至少一个所选通道的真实值保留在该单位轴内，查询直接使用原始采样而非显示抽稀点。纵轴平移保持当前格数和每格跨度，以整格移动，不重新吸附自动刻度公式；自动范围及缩放继续遵守精确刻度规则。已选参数在完整记录中均无有效数据时禁用图表鼠标操作；仅当前时间选区为空时仍可横向移动或调整范围。拖动期间的光标保持至释放、取消或窗口失焦。详见 [曲线平移边界与最新采样点对齐](chart-pan-limits-20261118.md)。

手机在纵轴刻度区双指捏合可独立缩放对应单位；在绘图区双指捏合继续缩放横轴。单指长按约 0.45 秒后，绘图区拖动框选时间、纵轴上下拖动按当前刻度整格平移，沿用最小 1 秒及原始采样可见性规则。长按前滑动取消等待，水平滑动保留时间平移，上下滑动滚动页面。第二根手指加入、触摸取消、窗口失焦或离开页面取消未提交框选；这些手势不改变原生采样与记录状态。详见 [手机曲线触屏手势](chart-touch-20261118.md)。

鼠标静止时浮窗随图表刷新继续显示，移出图表后隐藏；圆点按浮窗对应的原始采样绘制，支持未参与抽稀显示的采样点。绘图区鼠标拖动按起始范围及物理指针位移计算，通过指针捕获维持手势；Ctrl + 左键拖动用十字指针框选水平范围，纵轴区域 Ctrl + 左键上下拖动按整格平移该单位轴。下方范围条保留拖动和端点调整，关闭空白区域框选及十字指针，并缩小与图表的距离。桌面悬停横轴或某个单位纵轴时，按住 Ctrl 并滚动滚轮只缩放对应轴；纵轴每次直接切换到下一档合法比例，不再累积不可见范围。图表绘图区同样需要 Ctrl + 滚轮，普通滚轮滚动页面。手机双指缩放按手势起始距离计算并减弱变化幅度，逐帧合并更新，不叠乘每次触摸事件。拖动曲线、主图框选或范围条期间，原生采集和记录继续，图表暂缓应用新数据，松开后补上，避免刷新中断手势。“重置缩放”同时恢复横轴和全部纵轴，与截图、导出按钮使用相同尺寸。时间刻度使用竖向虚线网格；每条纵轴固定在其对应位置，相对时间零点不合并轴线。数据为空时不显示中央提示、横轴时间标签或悬停指示线。操作与验证见 [曲线配色与鼠标范围操作](chart-controls-20261118.md)。

实时、当前记录及历史记录的曲线均提供“全屏”按钮，放在右下角“重置缩放”右侧。桌面端让图表占满应用窗口，保留坐标、曲线、浮窗，以及顶部与“退出全屏”同排的参数复选框，不显示页面导航、卡片标题、范围条、导出栏或高度手柄。全屏使用同一个 ECharts 实例，当前选区、手动横纵轴缩放、完整数据和实时采样保持；窗口高度决定全屏刻度格数，退出后恢复原卡片高度与焦点，用户保存的高度不变。可点击退出，桌面也支持 Esc。

Android 通过原生窗口切换横屏并隐藏状态栏、导航栏，支持两个横屏方向；系统返回键先退出图表，退出或卸载曲线视图时恢复原先的方向和系统栏状态，不断开 USB / BLE、不修改采样和录制。手机浏览器尝试系统全屏及横屏锁定；系统不允许锁定时，图表视口按横向布局旋转，仍可退出。Android 横屏、沉浸式系统栏及返回键由原生代码实现；浏览器模拟验证不替代手机实机验收。

外部 `Time(D.hh:mm:ss.ms)` 格式仍按 `DateTime` 元数据作为真实起点。用户提供的 `NubiaZ70Ultra_20261002_184206.csv` 共 43,467 点、4,346.6 秒，补算结果约为 24.380606 Wh、2734.796840 mAh；它们是应用积分值，不是手机或 BW150 的设备累计回读。

导入保留每一行采样及其原始毫秒时间，重复时间的不同采样也保留。原始记录与曲线显示分开：浮窗按鼠标所在时间二分查找最近的原始采样，再从同一行读取全部勾选参数；显示层分别保留各通道峰谷不会造成浮窗参数缺失或错行。源文件未提供的温度、转速等通道仍留空，功率缺失时由电压与电流计算。

大文件的解码、CSV 解析、排序、累计量补算、全量统计和多级峰谷索引在独立 Web Worker 中执行，完成后通过可转移的类型化数组交付；主界面每批还原 8192 行完整采样，期间仍可响应导航。记录达到 2,000 点时启用可见范围懒加载：根据绘图区横向 CSS 像素数划分时间区间，每个像素、每条曲线保留原始最小值和最大值。另保留可见范围端点及左右相邻采样以保证边界连续；真实暂停和缺失参数插入空值标记，避免错误连线。放大到可见原始点不超过每像素两个时直接显示全部原始点，调整窗口宽度或进入全屏后重新计算点数。

多级索引缓存每组数据的最小值、最大值、数量及求和，拖动、缩放时二分定位时间范围并查询索引，避免反复遍历全文件。图表范围始终覆盖原始时间域；连续操作使用约 32 ms 的范围事件节流和逐帧合并，只合并更新曲线数据，保留当前拖动状态。统计与明细在操作停顿 120 ms 或拖动结束后更新，统计查询使用原始范围的精确聚合；电量、容量仍不计算平均值。导出在点击时立即读取最新选区，完整导出选区内所有原始采样，截图也先更新当前范围。

完整记录的累计量、通道统计和索引按不可变采样数组缓存，翻页、切换曲线和纵轴缩放不会重新解析 CSV。缩放状态仅读取 ECharts 的 dataZoom 组件，不通过 getOption 复制整份曲线。本方案对显示数据实行懒加载，CSV 本身仍完整解析并保存在内存中，以保留统计、积分、明细及导出的全部原始数据。Worker 在成功或失败后均终止，不保留后台解析实例。导入失败仍保留上一次成功记录，记录库只登记完整解析成功的文件。

操作成功、失败通知使用 Fluent 悬浮通知，不占页面布局；发出后 3 秒自动开始关闭，亦可手动关闭。悬停或聚焦不会延长关闭时限。持续状态和字段校验仍在对应区域显示。

曲线默认线宽为 1，已手动保存的其他线宽继续使用原值；恢复默认后回到 1。“应用更改”和“恢复默认”通过同一悬浮通知显示“已保存”，设置卡片底部不再保留固定状态文字。
