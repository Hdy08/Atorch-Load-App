# 连接与数据记录

## 自动连接

前台应用首次读取原生连接状态后，等待约 1.5 秒开始寻找设备。每轮先枚举 USB 并依次尝试兼容设备；未连接成功再扫描 BLE。BLE 扫描结束后重新枚举 USB，优先使用扫描期间插入的 USB，否则尝试发现的 BLE。已连接时保持当前通道；断线后重新进入自动寻找流程。

每轮结束后等待 5 秒再尝试，失败设备路径冷却 30 秒。首次缺少 BLE 权限时可请求一次系统授权；拒绝后本轮应用生命周期内不反复弹窗，仍检查 USB。蓝牙关闭、系统定位要求未满足等情况等下轮重新检查。手动管理窗口、其它应用任务、Root 角色切换、固件页面及后台状态让出自动扫描；开始手动扫描前先取消并等待自动扫描结束，迟到结果不能触发连接。IAP 升级接口不会自动连接为普通监测设备。

自动连接只建立监测连接，不发送启停、目标值、按键或累计清零命令。Root USB-C 直连仍需用户在管理窗口启用。

## 自动保存

记录在 Rust 设备线程中写入应用数据目录 `recordings/`，每个有效点落盘刷新，不依赖 WebView 的刷新频率。

| 设备 / 状态                         | 采样缓存                   | 自动 CSV                          |
| ----------------------------------- | -------------------------- | --------------------------------- |
| USB，首次读回为未启动 / 停止        | 暂停采样，继续读取设备状态 | 等待启动                          |
| USB，首次读回为运行，或停止变为运行 | 开始 / 继续采样            | 首次创建，之后追加                |
| USB，运行变为暂停 / 停止            | 暂停采样，继续读取设备状态 | 暂停，保留文件与起点              |
| USB / BLE，采样暂停                 | 停止追加                   | 停止追加                          |
| BLE，采样开启                       | 持续接收                   | 创建 / 继续追加；设备运行状态未知 |

恢复运行或采样后续写同一个文件。清空已有数据仍需确认；成功后结束当前自动文件并重置当前缓存和计时，下次有效采集新建文件。自动文件保留在原目录，**不自动加入本机记录库**。断开时完成当前文件。写入失败单独显示记录错误，设备监测与控制继续可用；USB 下次停载后再次运行会尝试恢复记录。

USB 自动同步只发生在本次连接首次读到有效运行状态，以及运行标志实际变化时。连续相同报文不改变用户手动选择：运行中手动暂停保持暂停，停止时手动继续也能记录；下一次设备启停变化重新同步。BLE 没有核准的运行标志，保持采样按钮控制。

自动文件追加 `ELAPSED_MS,SEGMENT_ID` 列，记录排除暂停的单调有效时长及采样分段。当前缓存亦保留分段；导出存在时间元数据时带上这两列，重新导入后仍保留暂停边界。旧 CSV 及原有兼容录制接口继续可读。升级确认时，只有负载已确认停止且记录暂停，才会先保存关闭记录再独占 USB；仍在写入时禁止升级。

## 当前与历史

“数据记录”仅有“当前记录”和“历史记录”两个页签。当前记录使用本次连接的实时缓存（最近 7,200 点）；历史记录通过系统文件窗口导入外部 CSV，导入成功后切换到该文件。

本机记录库仅登记**手动导入及成功导出的 CSV**，不扫描自动记录目录。索引位于应用配置目录的 `record-library.json`，只保存文件路径、名称、大小及修改时间，不复制 CSV 或存储采样内容。重复导入同一路径更新一条记录；不同路径的同名文件分开显示。取消文件窗口、解析失败或取消导出不登记记录。Windows 保存完整文件路径；Android 使用系统 `ACTION_OPEN_DOCUMENT` / `ACTION_CREATE_DOCUMENT` 返回的 URI，并持久保留读取授权，供重启后打开。浏览器预览的普通文件输入只提供临时查看；持久记录库使用原生应用。

记录左侧可勾选，右上角“删除记录”只更新索引，绝不删除或修改磁盘 CSV，也不删除 Android 文档。删除正在查看的导入记录或库内记录后，同步清空其曲线、统计、明细与选区，并禁用导出和截图；删除其他记录保留当前视图，本次实时缓存也不清空。文件被移动、删除或读取权限被撤销时会明确报错，可重新导入更新引用。单份文件超过 50 MB 会整体拒绝导入，不以截断方式载入。

电量与容量不计算平均值，其统计平均值栏显示“—”。已有的有效累计值，包括零值，直接保留。缺失项在整份按时间排序的记录上补算：

- 电量：`Wh += (|P前| + |P后|) / 2 × Δt(ms) / 3,600,000`。
- 容量：`mAh += (|I前| + |I后|) / 2 × Δt(ms) / 3,600`。

首点从零开始，后续原始累计值可重新锚定缺失区间。优先使用 `elapsedMs` / CSV `ELAPSED_MS` 的间隔，否则使用真实时间差；重复时间不增加累计值，倒退的有效时长不产生负积分。功率和电流自身保留符号，仅累计量取绝对值，兼容充电负电流文件。统计使用 `电量 / Wh (计算)`、`容量 / mAh (计算)` 标注，删去标题下的积分说明。积分累加保留内部精度；曲线浮窗最多 4 位小数，统计和明细最多 3 位；CSV 导出保留原始测量值与积分内部精度，避免很小的累计值被舍入为零。

图表缩放发生在补算之后，范围变化不会重置累计起点。移除开始 / 结束日期输入行，采样统计、明细与导出统一使用图表选区；选区落在空档时有效点数为零，均值等显示“—”，不能导出虚构采样。导出保存所选范围的全部采样点及补算的累计数值，原文件不修改。CSV 仍使用真实时间戳；曲线可切换真实 / 相对时间并共享记忆设置。

采样明细默认每页 10 条，可在右上角选择 10 / 20 / 50 / 100 条，设置保存在本机并用于当前与历史记录。选择器右侧输入页码后按 Enter 或移出输入框即可跳转，超出范围时限制到首页或末页。明细维持最新在前；分页仅影响表格，不截断曲线、统计或导出的采样点。

真实时间曲线在采样分段变化、有效时长揭示暂停间隔，或旧文件存在明显采样空档时断开线条与阴影，不补零，不插值。分段标记只产生图表中的空值，不进入统计、积分或 CSV。相对时间仍扣除暂停间隔。范围右端保持最右边时随最新数据更新，左端保留选择的时间；右端离开末端时锁定所选历史区间。

鼠标静止时浮窗随图表刷新继续显示，移出图表后隐藏；悬停横轴或某个单位纵轴时，滚轮仅缩放对应轴。拖动曲线或范围条期间，原生采集和记录继续，图表暂缓应用新数据，松开后补上，避免刷新中断手势。“重置缩放”同时恢复横轴和全部纵轴，与截图、导出按钮使用相同尺寸。时间刻度使用竖向虚线网格；每条纵轴固定在其对应位置，相对时间零点不合并轴线。数据为空时不显示中央提示、横轴时间标签或悬停指示线。

实时、当前记录及历史记录的曲线均提供“全屏”按钮，放在右下角“重置缩放”右侧。桌面端让图表占满应用窗口，只保留坐标、曲线、浮窗和“退出全屏”，不显示页面导航、卡片标题、范围条、导出栏或高度手柄。全屏使用同一个 ECharts 实例，当前选区、手动横纵轴缩放、完整数据和实时采样保持；窗口高度决定全屏刻度格数，退出后恢复原卡片高度与焦点，用户保存的高度不变。可点击退出，桌面也支持 Esc。

Android 通过原生窗口切换横屏并隐藏状态栏、导航栏，支持两个横屏方向；系统返回键先退出图表，退出或卸载曲线视图时恢复原先的方向和系统栏状态，不断开 USB / BLE、不修改采样和录制。手机浏览器尝试系统全屏及横屏锁定；系统不允许锁定时，图表视口按横向布局旋转，仍可退出。Android 横屏、沉浸式系统栏及返回键由原生代码实现；浏览器模拟验证不替代手机实机验收。

外部 `Time(D.hh:mm:ss.ms)` 格式仍按 `DateTime` 元数据作为真实起点。用户提供的 `NubiaZ70Ultra_20261002_184206.csv` 共 43,467 点、4,346.6 秒，补算结果约为 24.380606 Wh、2734.796840 mAh；它们是应用积分值，不是手机或 BW150 的设备累计回读。

导入保留每一行采样及其原始毫秒时间，重复时间的不同采样也保留。曲线不再分别执行 LTTB 抽稀，每条曲线使用相同的完整时间序列，避免全范围下曲线时间点错位和浮窗参数缺失。源文件未提供的温度、转速等通道仍留空，功率缺失时由电压与电流计算。

大文件的解码、CSV 解析、排序、累计量补算、全量统计和曲线数据准备在独立 Web Worker 中执行，完成后通过可转移的 Float64Array 交付数据；主界面分批还原完整采样，期间仍可响应导航。超过或等于 20,000 点时，ECharts 的多条曲线共用完整精度的数据集，不为每个通道复制一套对象数组，不抽稀、不限制采样点数。真实时间的空档只进入对应曲线数据集，相对时间仍连续；没有空档的文件在两种时间模式间共用同一缓冲区。

完整记录的累计量、通道统计及曲线源数据按不可变采样数组缓存，翻页、切换曲线和纵轴缩放不会重新解析 CSV。缩放状态仅读取 ECharts 的 dataZoom 组件，不通过 getOption 复制整份曲线；没有新数据的拖动结束也不重建曲线。Worker 在成功或失败后均终止，不保留后台解析实例。导入失败仍保留上一次成功记录，记录库只登记完整解析成功的文件。

操作成功、失败通知使用 Fluent 悬浮通知，不占页面布局；发出后 3 秒自动开始关闭，亦可手动关闭。悬停或聚焦不会延长关闭时限。持续状态和字段校验仍在对应区域显示。

曲线默认线宽为 1，已手动保存的其他线宽继续使用原值；恢复默认后回到 1。“应用更改”和“恢复默认”通过同一悬浮通知显示“已保存”，设置卡片底部不再保留固定状态文字。
