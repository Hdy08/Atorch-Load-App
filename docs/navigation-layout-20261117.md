# 导航、窗口与通知交互调整（2026-11-17）

继续使用 Fluent 官方 `Nav / NavItem`，按本轮用户要求调整尺寸和状态。不改变 USB / BLE 协议、负载控制命令或固件升级行为。

## 导航与页面布局

- 桌面展开 / 收起侧栏为 228 / 72 像素，四周内边距统一 16。导航项共用 10 像素水平内边距及 20 像素图标；收起时图标居中。展开与收起的图标中心相对侧栏左边缘均为 36 像素，指示条起点均为 16，二者不重叠。
- 正常导航项透明；选中与悬停时使用 `colorNeutralBackground4Hover`，保留官方焦点、字号、圆角和 Filled / Regular 图标。
- 实时页图标改为官方 `PulseSquare`。
- 手机竖屏使用五项等宽底栏，设备入口仍在最右；使用一根三像素底部指示条随当前页签移动，CSS 过渡读取 Fluent 动画 token，减少动态效果时禁用过渡。
- 手机实际屏幕方向为横屏时使用桌面侧栏及相同展开 / 收起策略，不以软键盘造成的视口高度变化判断方向。手机页面边距仍为 16。导航不显示分隔线。
- 手机竖屏标题采用 32 像素行高，一般标题行最小高度为 32；实时页标题区为 84，仅留出默认控制器所需空间。标题区与下一项间距保留 16。
- 桌面标题与右上角操作按钮顶对齐，布局框距内容区顶部均为 24，不再因标题行居中增加 2 / 6 像素偏移。

## 通知、数据及滚动条

实时页通知顶边距悬浮控制器默认位置底边 16 像素；控制器被拖动后，通知仍以默认位置作为锚点。应用设置通知顶边距右上角操作按钮底边 16。布局测量抵消页面过渡和滚动偏移，并将物理坐标换算为当前 UI 缩放坐标。移除 Toast 容器自带的首项外边距，通知之间使用容器 gap 保持间距。

统计和明细的缺失值 `—` 使用普通行内元素，靠数值单元格右边缘显示，不再为缺失值预留小数列。有效数值仍按原有精度补零并对齐小数点。

页面滚动条在滚动、滚轮操作或鼠标接近右边缘时显示，空闲 1 秒后隐藏；显隐只改变颜色，保留相同滚动条宽度，不使页面或卡片跳动。鼠标移动检测使用视口右边缘，不在曲线每次指针移动时重新测量 DOM 布局。

## 窗口与浏览器默认交互

Windows 始终保留系统窗口装饰和原生最小化 / 最大化 / 关闭按钮。不再在标题栏配色失败时调用 `set_decorations(false)`；系统支持配色时继续尝试使用导航背景和文字色，不支持时由系统绘制标题栏。窗口拖动、双击最大化、调整大小及关闭仍由系统处理，固件升级期间原有关闭拦截继续生效。

Windows 初始化 WebView2 时关闭默认右键菜单、开发工具、浏览器缩放和浏览器快捷键；复用工作区已有 `webview2-com 0.39.1`。前端同时拦截所有上下文菜单及刷新、打印、另存为、浏览器导航、浏览器缩放等快捷键，包括 F5、Ctrl+R、Ctrl+Shift+R、F12。文本选择、复制、粘贴、剪切、撤销、重做、Tab、Enter 和应用自身图表操作继续保留。

## 验证与输出

测试采用隔离的 IPC 模拟数据，未启动原生应用控制实体负载。浏览器验证覆盖桌面 850 / 1200 / 1440 / 2000、手机竖屏 / 横屏、50% / 125% / 200% 缩放、导航命中与动画、通知间距、标题顶对齐、缺失值右对齐、快捷键及滚动条显隐。

25 个不同的界面用例最终通过，按主运行及定向复验中相同文件、完整用例标题的最新结果合并；原始失败记录仍保留，不能将合并结果理解为一次无失败的完整运行。缺失值用例改用允许为空的可选 MOS 温度字段，并在导入完成后检查，避免把必填电流空值的拒绝导入或旧空表误当成显示问题。

TypeScript、Prettier、Rust 格式与 Windows `cargo check` 通过。Windows x64 NSIS 与 Android arm64 调试 APK 完成构建，两端原生程序均含五项本次前端资源，解压后的 SHA-256 一致；APK ZIP 完整性与 v2 调试签名验证通过。

安装包为 `Atorch-Load_0.1.0_windows-x64_navigation_20261117-setup.exe` 和 `Atorch-Load_0.1.0_android-arm64_navigation_20261117_debug.apk`，位于本轮 artifacts 目录。`SHA256SUMS.txt` 记录安装包与独立 EXE 哈希，`ui-verification.json`、`source-manifest.json` 和 `release-report.json` 记录验证结果及工作区来源。

最终构建与校验结果保存在 `artifacts/navigation-layout-20261117/release-report.json`；本轮窗口原生配置通过 Windows 编译检查，真机 Android 系统栏行为未在本轮重新验收。
