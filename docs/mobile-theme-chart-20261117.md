# 手机布局、主题、曲线与自动记录（2026-11-17）

本轮同时交付 Windows x64 安装包和 Android arm64 调试 APK。以下验证和安装包对应收窄模式卡片之前的构建快照；后续将卡片改为最小 160 像素的自动网格，与此前完成的应用修改一并提交源码，未重新生成安装包。未刷写固件或执行实物负载控制。

## 自动记录

应用设置的记录页改为“自动记录”卡片，首行选择关、跟随设备或设置阈值，默认关。开始和停止规则独立启用、编辑和保存；未应用的草稿不会被轮询快照覆盖。“恢复默认”仅更新当前页签草稿，“应用更改”保存到原生配置。旧版开启的记录开关迁移为跟随设备，关闭或缺失时保持关。

跟随设备提供“启动时开始”“关闭时停止”及各自的延迟；设置阈值提供开始、停止开关，电压 / 电流 / 功率、小于 / 大于、带单位的数值和保持时间。USB 可用设备运行标志，USB / BLE 均可用测量阈值；BLE 不推断未经核准的运行标志。

“延迟”和“保持”都按连续保持执行，条件不满足立即清零，再次满足重新计时。时间默认 `0.0 s`，步进 `0.1 s`，显示一位小数；前端和原生都拒绝负值、无效值和超过一位小数的时间。原生单调时钟计时，在新遥测到达时触发，实际判定间隔受查询或上报频率影响。开始、停止同时成熟时停止优先。

手动暂停暂时屏蔽自动开始，观察到开始条件不满足后才解除；随后再次满足必须重新保持。自动暂停后可以手动继续，已经触发的停止条件不会在持续满足期间重复触发；先解除、再满足并保持后重新生效。尚在保持计时的停止条件继续受该计时控制。最新行为及验证见 [精确刻度与手动继续](chart-exact-ticks-resume.md)。采样暂停会同时停止缓存、有效时长和 CSV 追加，遥测仍继续接收；恢复时续写当前文件。自动文件仍不自动加入记录库。

详细规则及记录库约定见 [连接与数据记录](recording.md)。

## 布局、模式和主题

- 手机首次和恢复默认缩放为 75%，桌面为 100%，已保存的缩放值继续保留。
- 手机横屏也使用紧凑的标题高度；实时页根据悬浮控制器实际大小保留空间，能同排时与标题同排，消除固定占位产生的大块留白。控制器和通知继续对齐页面右边缘，通知与控制器默认位置或设置按钮底部相距 16 像素。
- 模式卡片仅显示模式代码和标题，说明在悬停提示中；整张卡片支持鼠标点击和 Enter / 空格选择，不再显示内部切换按钮、底部描述或重复的当前模式文字。设备运行时的模式切换限制保持。
- 电量、容量和风扇转速统一使用简短名称；蓝牙清零入口为清空电量、清空容量、清空计时。
- Windows 重新应用跟随系统时独立读取原生系统应用背景色，再同步内容与原生窗口主题；窗口恢复焦点时也刷新。显式主题不再通过 WebView 的受控媒体查询误判系统主题。
- 明暗切换使用原生 View Transitions，约 200 ms；首次加载及系统减少动态效果时直接切换，不支持原生过渡时使用短淡入回退。

## 曲线交互

桌面绘图区和坐标轴都需要 Ctrl + 滚轮才缩放；普通滚轮滚动页面。纵轴只缩放当前单位轴，横轴及绘图区缩放时间。手机双指缩放以手势开始时的距离和范围计算，比例取平方根，并逐帧合并更新，避免触摸事件数量叠乘放大灵敏度。

75% 界面缩放下，全屏图表的逻辑画布尺寸按缩放补偿，实际显示矩形仍覆盖整个窗口。验证同时检查 Android 横屏请求、返回退出、卸载恢复，以及手机浏览器不能锁定方向时的旋转回退。
