# Atorch Load

**当前版本 0.1.0** · **Windows / Android**

面向 ATORCH BW150 电子负载的监控与控制应用，使用 Tauri、React 和 Fluent UI 构建。

## 主要功能

- **设备连接** 支持 USB 与蓝牙低功耗（BLE）、自动连接和 BLE 面板遥控。
- **实时监控** 显示电压、电流、功率、电阻、电量、容量、温度与风扇转速。曲线支持多轴、缩放、范围选择与全屏查看。
- **记录与回看** 支持手动记录、按负载状态或测量阈值自动记录、CSV 导入导出、区间统计与图表截图。
- **设备控制** 通过 USB 切换负载模式、设置目标值和保护参数、启停负载。从设备设置页管理校准和维护。
- **USB 固件更新** 支持选择文件和目标设备、查看写入进度及打开传输日志。
- **界面设置** 可调整主题、强调色、界面缩放以及实时与历史曲线共用的外观。
